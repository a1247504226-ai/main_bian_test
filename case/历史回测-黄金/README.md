# 黄金 AU 趋势策略（历史回测 + 实盘信号）

本目录是黄金（上期所 AU）单品种趋势策略的完整落地包：**回测验证 + 每日信号 + 定时任务**。

## 一、文件说明

| 文件 | 作用 |
|---|---|
| `gold_strategy.py` | **主策略脚本**：拉取黄金日线 → 计算当前信号 → 输出方向/建议仓位/止损价 |
| `gold_backtest.py` | 回测脚本：复用同一套信号逻辑，输出风险档位表与权益曲线 |
| `config.json` | 策略参数（改这里即可调参/调风险） |
| `run_strategy.bat` | 运行入口（定时任务实际调用的就是它） |
| `install_task.bat` | **安装** Windows 定时任务（每天 15:30 自动跑信号） |
| `uninstall_task.bat` | **卸载** 定时任务 |
| `requirements.txt` | Python 依赖 |
| `output/` | 信号 CSV、权益曲线图 |
| `logs/` | 运行日志 |

## 二、策略逻辑（鱼身趋势 + 波动率目标 + 吊灯止损）

1. **趋势过滤**：收盘价 > 慢均线(MA60) 视为多头环境，< 视为空头环境。
2. **入场（吃鱼身）**：价格回调后**重新上穿**快均线(MA10) → 做多；下穿 → 做空。不追突破尖（鱼头），不熬末端（鱼尾）。
3. **失效离场**：入场后 2 根 K 线内收盘价重新跌破/上穿快均线 → 平仓。
4. **趋势末端止盈**：收盘价跌破/上穿慢均线 → 平仓。
5. **吊灯止损**：多头止损 = 持仓期最高价 − 3×ATR；空头对称。
6. **仓位（关键）**：按年化目标波动率 `target_vol` 反比定仓，让风险恒定——这是把夏普从 0.48 提到 0.63 的核心增强。

## 四、定时任务

- **安装**：右键 `install_task.bat` → 以管理员身份运行（若失败）。成功后任务名 `GoldTrendStrategy`，每天 **15:30** 自动运行。
- **卸载**：双击 `uninstall_task.bat`。
- **查看/手动**：任务计划程序 → 任务计划程序库 → `GoldTrendStrategy`。

> 15:30 在日盘收盘（15:00）之后，此时当日日线已完整，信号用于下一交易日。

## 五、风险档位（改 `config.json` 的 `target_vol`）

同一策略，`target_vol` 就是复利/回撤的旋钮（历史 2010–2026 回测）：

| target_vol | 年化 | 最大回撤 | 夏普 |
|---|---|---|---|
| 0.08 | ~4.5% | ~-17% | 0.63 |
| 0.12 | ~6.6% | ~-25% | 0.63 |
| **0.15（默认）** | **~8.1%** | **~-30%** | **0.63** |
| 0.20 | ~10.4% | ~-39% | 0.63 |
| 0.30 | ~14.0% | ~-46% | 0.62 |

- 想更稳：调低 `target_vol`（如 0.10–0.12）。
- 想更高复利：调高 `target_vol`，但回撤同步放大。
- 其它参数：`ma_slow/ma_fast/fail_bars/trail_atr` 为信号参数，`account_equity` 为你的账户权益（用于算手数），`contract_multiplier` 为合约乘数（AU=1000 克/手）。

## 六、重要提示

- 本包为**历史回测 + 信号提示**工具，**不构成投资建议**，不自动下单。
- 期货杠杆风险极高，可能损失全部本金；请先用小资金或模拟盘验证。
- 历史收益不代表未来。策略在 2011–2015 黄金震荡/下跌段曾出现连续负收益区间，需有心理准备。
- 数据来源：新浪财经期货（akshare），若接口变动脚本会自动回退直连新浪；仍失败请检查网络。

## 七、邮件推送（新买入信号）

- **配置文件**：`email_config.json`（含 163 授权码，请勿外传/上传）。
- **触发条件**：策略出现**新的做多信号**时自动发信到 `656677027@qq.com`。
  - 判定：最近一次进入多头在 `recent_days`（默认 7）天内，且该信号日期未被通知过。
  - 默认只推买入（`notify_on_new_long=true`），卖出不推（`notify_on_new_short=false`），可在 `email_config.json` 改。
- **去重**：`state.json` 记录已通知的信号日期，同一信号不会重复发。
- **测试发信**：`python test_email.py`（会真实发一封测试邮件）。
- **定时任务**：任务名 `GoldTrendStrategy`，每天 **14:45** 自动运行（已创建）。
  - 为什么 14:45：场外黄金基金 **15:00 截止申购**，必须提前拿到信号才能当天生效；14:45 留 15 分钟下单。
  - 查看：任务计划程序 → 任务计划程序库 → `GoldTrendStrategy`
  - 卸载：双击 `uninstall_task.bat`
  - 注意：默认"仅在用户登录时运行"，若 14:45 未登录则不会触发。
- **盘中预判**：14:45 时当日日线未收盘，脚本用**实时价**构造今日临时K线来预判（数据源标注 `+实时预判`）。收盘前最后 15 分钟若反转，信号可能微调，请自行确认。
- **排错**：若报 `UnicodeEncodeError: 'ascii' ... EHLO`，是**计算机名含中文**导致，代码已用 `local_hostname='localhost'` 规避。

## 八、黄金基金版（只做多）说明

- 基金只能做多：**策略做多 = 申购/持有；策略空仓或做空 = 赎回/空仓**（不做空）。
- 邮件只推两个动作：**买入信号（申购）** 与 **卖出信号（赎回）**；`email_config.json` 里 `notify_on_long_exit=true`。
- 同参数历史表现（2010–2026，含成本）：

  | 版本 | 年化 | 最大回撤 | 夏普 |
  |---|---|---|---|
  | 多空版（期货） | 8.7% | -30.1% | 0.66 |
  | **只做多（基金）** | **8.8%** | **-20.9%** | **0.80** |
  | 买入持有 | 8.3% | -44.8% | — |

- 结论：只做多版本回撤明显更小（-20.9% vs 买入持有 -44.8%），更适合基金长期持有。
