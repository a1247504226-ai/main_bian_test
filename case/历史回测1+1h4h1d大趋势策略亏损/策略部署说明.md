| 项目 | 配置 |
|---|---|

## 二、下单金额怎么算（重点）

**不是固定金额，是按风险反推数量。**

```python
风险金额 = 权益 × 2%
止损距离 = ATR × 5
下单数量 = 风险金额 ÷ 止损距离
```

举例，权益 10000 USDT：

| 标的 | ATR | 止损距离 | 下单数量 | 名义价值 | 占用保证金(10x) | 止损亏 |
|---|---|---|---|---|---|---|
| BTCUSDT | 211.08 | 1055.42 | 0.189 BTC | 14851.86 | 1485.19 | 200 USDT |
| ETHUSDT | 10.62 | 53.12 | 3.765 ETH | 9290.70 | 929.07 | 200 USDT |
| SOLUSDT | 0.7477 | 3.7384 | 53.49 SOL | 5512.68 | 551.27 | 200 USDT |

**三个标的止损亏的钱完全一样（200 USDT），但下单数量差 280 倍**——
因为 SOL 的波动比 BTC 大得多，止损距离也远得多，所以数量必须小。

完整对照表见 `backtest/results/下单金额对照表.md`（含 1000 / 5000 / 10000 / 50000 / 100000 五档）。

> 关键点：名义价值可能超过权益（BTC 那行 14851 > 10000），这是正常的。
> 因为止损只有 1.34%，亏 2% 就需要 1.49 倍名义敞口。10x 杠杆完全够用。

## 三、部署步骤

### 1. 环境

```bash
pip install requests pandas numpy
```

用 Python 3.9+ 即可（本机 managed 3.13 没装 requests，用系统 3.9）。

### 2. 设置环境变量

```bash
# 先在测试网跑
set BINANCE_ENV=TEST
set BINANCE_API_KEY=你的测试网key
set BINANCE_API_SECRET=你的测试网secret

# 可选：调整风险
set RISK_PER_TRADE=0.02
set LEVERAGE=10
set MAX_TOTAL_RISK=0.06

# 可选：网络受限时指向镜像
set BINANCE_FAPI_BASE=https://你的可达地址
```

### 3. 三步上线

```bash
# 第一步：测算下单金额（不联网下单，只看数字对不对）
python binance_combined_signal_trader.py --calc --balance 10000

# 第二步：只看信号，确认指标读得出来
python binance_combined_signal_trader.py --scan

# 第三步：干跑（走完整流程但不下单）
python binance_combined_signal_trader.py --dry-run

# 第四步：测试网实跑 1-2 周，确认开仓/止损/止盈都正常
python binance_combined_signal_trader.py

# 第五步：实盘
set BINANCE_ENV=MAIN
python binance_combined_signal_trader.py
```

## 四、脚本做了哪些保护

| 风险 | 处理方式 |
|---|---|
| 用了未收盘 K 线（未来函数） | `get_klines` 按服务器时间过滤 `close_time <= now` |
| 止损单挂了但没成交 | 止损挂失败 → **立即市价平仓**，绝不裸奔 |
| 脚本掉线 | 止损止盈都是交易所侧条件单，掉线也生效 |
| 止损单被误删/丢失 | 每轮扫描检查条件单是否存在，缺了自动补挂 |
| 网络超时导致重复开仓 | `newClientOrderId` + 超时后按 cid 反查 |
| 成交价取不到（avgPrice=0） | 三级兜底：订单 → 成交明细 VWAP → positionRisk |
| 精度报错 -1111 | 全部用 `Decimal` + `quantize`，按 `tickSize`/`stepSize` 取整 |
| 时间戳漂移 -1021 | 启动时用 `/fapi/v1/time` 校准 offset |
| 限流 429/418 | 指数退避重试 |
| 状态文件写坏 | 先写 `.tmp` 再 `os.replace` 原子替换 |
| 三个标的同时满仓风险叠加 | `MAX_TOTAL_RISK=6%` 上限拦截 |
| 止损单缺失导致裸奔 | 每轮检查，缺失即补挂 |

## 五、⚠️ 风险警告

**58% 最大回撤意味着账户会腰斩再腰斩。**

- 最长水下时间约 **749 天（2 年）**——从高点跌下去要 2 年才回本
- 胜率只有 42.9%，意味着**连续亏 8-10 笔是正常现象**，不是策略坏了
- 三个标的同时止损 = 单日回撤 6%

如果你不能承受，改一个参数就行：

```bash
set RISK_PER_TRADE=0.005     # 回撤降到约 19%，年化降到约 13%
```

回撤与风险近似线性：风险减半，回撤大致减半，年化也大致减半。

**资金量建议**：

| 账户规模 | 建议单笔风险 | 理由 |
|---|---|---|
| < 1 万 USDT | 0.5% | 小资金先求活下来 |
| 1-10 万 | 0.5% ~ 1% | 平衡 |
| > 10 万 | 0.25% ~ 0.5% | 绝对亏损金额已经很大 |
