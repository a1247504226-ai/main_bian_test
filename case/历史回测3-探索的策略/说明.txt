③ 新增 alert.py —— 价格触发的风控提醒，只提醒、不自动下单，你自己操作：

bash

python alert.py            # 到价就发信（同类提醒当天只发一次）
python alert.py --dry-run  # 只看触发没触发
python alert.py --force    # 强制发一封测试
在 config.json 的 risk 段配置：

json

"risk": {
  "stop_mode": "trail_atr",   // none | trail_atr | fixed_pct
  "trail_atr": 5.0,           // 移动止损 = 持仓最高价 − 5×ATR
  "take_profit_pct": 0.0,     // 止盈，0 = 不设
  "liq_warn_pct": 0.10,       // 距爆仓 <10% 预警
  "max_alerts_per_day": 3
}
建议用 trail_atr 而不是 fixed_pct —— 它是移动的，仓位涨上去止损位跟着抬，能锁利润；固定百分比那个正是被证伪的过拟合方案。如果你只想要最少的干扰，设 "stop_mode": "none"，那就只保留爆仓预警。

一个提醒：alert.py 的定位是「极端行情保险」，不是日常操作工具。如果你开始频繁按提醒位手动进出，那你实际上是在执行一个已经被回测否定的策略——收益大概率不如老老实实等信号反转。
