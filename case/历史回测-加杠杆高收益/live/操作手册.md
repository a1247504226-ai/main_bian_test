# BTC 趋势策略 · 实盘监测器 操作手册

> 版本：2026-10-25 · 适配 Windows 10/11
> 本监测器**只做信号监测 + 邮件推送 + 纸上权益跟踪，不自动下单**。真正的买卖由你在交易所手动执行。
>
> 📄 上级目录另有两份配套表：`信号明细表.html/.csv`（270 笔逐笔交易，从 1000U 起）、`策略明细表.html`（完整规则）。

---

## 一、这个策略在做什么

| 项目 | 规则 |
|---|---|
| 信号周期 | **4 小时**判定一次（新 4h K 线收盘后才重算） |
| 趋势判定 | 4h `EMA50 > EMA200` 且收盘价 > EMA200 → **做多**；反向 → **做空**；否则 → **空仓** |
| 止损检查 | **每小时**一次（8 × ATR(14)，基于 1 小时线） |
| 冷却 | 止损离场后，冷却 24 根 1 小时线才允许再进场 |
| 止盈 | **不设固定止盈**（回测证明固定止盈在 2x 杠杆下必然归零） |
| 杠杆 | 默认 **2x**（`config.json` 可改） |
| 仓位 | 满仓：名义仓位 = 权益 × 杠杆（100% 权益作保证金，不留现金） |
| 成本 | 手续费 0.05% + 滑点 0.03%，双边计，随杠杆放大 |

**回测参考（BTCUSDT 现货，2017-08 ~ 2026-10，约 9 年）**：2x 满仓复利终值约 **491 倍**量级（1000U → 约 49 万 U 量级，已扣手续费/滑点/资金费）。1x/3x 对比见上级目录 `杠杆对比_1x2x3x.html`。

> ⚠️ 回测是历史统计，不代表未来收益。3x 已被否决（样本外仅 1.05×、最大回撤 -89%、删掉最佳 5 笔就变 0.49×，超杠杆严重）。

## 二、运行前的前置条件

1. **Windows 10 / 11**
2. **Python 3.8 或更高版本**（装一次即可）
   - 下载：<https://www.python.org/downloads/>
   - 安装时**务必勾选** “Add Python to PATH”
   - 验证：打开 `cmd`，输入 `python --version` 能显示版本号即可
3. 能正常访问币安行情（`api.binance.com`）
4. 一个已开启 SMTP 服务的 163 邮箱（用于发信）+ 收件邮箱

> 本策略只用 Python 标准库，**不需要联网安装任何第三方包**（不需要 pip install）。

## 四、部署（三步走）

> 把整个 `live` 文件夹拷到目标电脑（例如 `D:\BTC策略\live`），然后：

### 第 1 步：邮箱授权码（已内置，可跳过）
授权码已写入 `config.json` 的 `email.password`，**开箱即用，无需再设置**。
- 如需更换：用记事本打开 `config.json` 改 `email.password`（或双击 `①设置邮箱授权码.bat` 写环境变量，环境变量优先级更高）。
- 授权码获取：登录 <https://mail.163.com> → 设置 → POP3/SMTP/IMAP → 开启 SMTP 服务 → 获取授权码（是"客户端授权码"，不是登录密码）。

### 第 2 步：一键安装
双击 **`install.bat`**。它会自动：
1. 探测可用的 Python；
2. 创建/修复虚拟环境 `.venv`（**可选**；即使没有 `.venv`，任务也会自动改用系统 `python` 运行，本策略纯标准库）；
3. 检查配置；
4. 注册 Windows 计划任务「BTC策略监测器」（**每小时零 2 分**运行，失败自动重试 3 次）。

> 若提示“注册计划任务失败”，请**右键 install.bat → 以管理员身份运行**。

### 第 3 步：测试邮件
双击 **`②测试邮件.bat`**，看收件箱是否收到测试邮件。收到即部署成功。

## 五、运行机制（部署好之后，无需人管）

- 计划任务 **每小时零 2 分**自动执行一次 `run_with_retry.bat`。
- 每次运行：
  - 有持仓 → **每轮都检查止损**（盘中高低点 + 实时价，跳空按开盘价成交）；
  - 空仓 → 只有出现**新的 4h 收盘**才重新判定信号；
  - 没有新信号且无持仓 → 快速跳过（不浪费请求）。
- **发邮件时机**：仅在发生「开仓 / 止损 / 趋势失效平仓」时推送。空仓且无变化时**不发**（避免刷屏）。邮件正文是 **HTML 表格**（摘要表 + 本次动作表）。
- **纸上权益**：从 **1000U** 起、按本机实时信号滚仓（与历史回测的 491x 无关）。
- 失败自动重试 3 次（间隔 30 秒），仍失败则写日志，等下个小时。

## 七、换电脑 / 迁移

1. 把**整个 `live` 文件夹**拷到新电脑（`.venv` 一起拷也没关系，install.bat 会自愈重建）。
2. 新电脑装好 Python 3.8+（勾选 Add to PATH）。
3. 授权码已在 `config.json` 里，随文件夹一起拷走，无需重设（如需更换用记事本改 `email.password`）。
4. 双击 `install.bat`。
5. 双击 `②测试邮件.bat` 验证。

> 同一台电脑**不要装两份**，计划任务名同为「BTC策略监测器」会冲突。

## 八、常见问题排查

| 现象 | 处理 |
|---|---|
| install.bat 提示“没找到 Python” | 装 Python 并勾选 Add to PATH；或已装但未生效，重开窗口 |
| 注册计划任务失败 | 右键 install.bat → 以管理员身份运行 |
| 收不到邮件 | ①确认授权码是“客户端授权码”不是登录密码；②163 已开启 SMTP；③看垃圾箱；④看 monitor.log 有无“邮件发送失败” |
| 提示“拉取 K 线失败/取数失败” | 网络无法访问币安，检查网络/代理；脚本会自动重试 |
| 想确认代码没坏 | 命令行运行 `python test_stop_gap.py`，输出 `PASS` 即正常 |
| 权益数字和交易所对不上 | 纸上权益是策略模拟值（不含资金费），仅供跟踪，不是真实账户 |

## 九、风险提示（务必阅读）

1. **2x 是满仓杠杆**：名义仓位 = 权益 × 2，100% 权益作保证金，**不留现金**。价格反向约 50% 才爆仓，但止损（约 4%~8% 波动）会先触发，正常行情不会到爆仓线。
2. **不自动下单**：本程序只发信号。你在交易所实际下多少、用不用满仓，**由你自己决定**——完全可只拿部分资金跟。
3. **极端跳空风险**：若价格直接跳空越过止损（开盘就远在止损外），成交价会按跳空开盘价计，实际亏损可能大于 8×ATR。
4. **纸上权益不含资金费**：真实永续合约有资金费（多付空收，长期略正），实际盈亏会有小幅差异。
5. **历史≠未来**：回测 491 倍是过去 9 年的统计结果，实盘可能长期横盘/震荡导致连续止损，请务必只用可承受亏损的资金。

## 十、参数调整（`config.json`）

| 字段 | 含义 | 默认 |
|---|---|---|
| `leverage` | 杠杆倍数 | 2.0 |
| `initial_equity` | 纸上权益起点（仅用于展示倍数） | 1000 |
| `stop_atr` | 止损 = N × ATR(14) | 8.0 |
| `cooldown_bars` | 止损后冷却多少根 1h | 24 |
| `ema_fast` / `ema_slow` | 趋势均线 | 50 / 200 |
| `fee` / `slip` | 手续费率 / 滑点率 | 0.0005 / 0.0003 |
| `email.sender` / `to` | 发件 / 收件邮箱（`to` 是数组） | 见文件 |

> 改完 `config.json` 保存即可，下一轮自动生效；**不要改 `signal_timeframe`/`filter_timeframe`**，否则与回测口径不一致。
