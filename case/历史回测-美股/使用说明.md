# 美股趋势信号 · 每日开盘前邮件提醒

> 每只标的：收盘站上 200 日均线 → 次日开盘持有；跌破 → 清空。
> **大盘牛熊开关**：SPY 跌破 MA200 → 全部清仓持币（不做空），重新站上再恢复做多。
> 每天（美股交易日）开盘前自动发一封邮件到你的邮箱，告诉你「今天该持哪几只、要不要调仓、大盘是否进入熊市防御」。

---

## 一、每天自动跑（已经帮你注册好了）

系统里已注册 Windows 计划任务 **`US_Trend_Signal_Daily`**：

- 触发时间：**每天 北京时间 20:30**（= 美东 07:30/08:30，开盘前）
- 动作：运行本目录的 `每日信号.bat --quiet`
- 只在**美股交易日**且在时间窗口内才发信；周末/美国法定节假日自动跳过，不发信也不报错
- 同一天重复跑（比如手动补跑）不会重复发信（按信号基准日去重）

**想改时间**：用管理员 PowerShell 改
```powershell
$t = Get-ScheduledTask -TaskName "US_Trend_Signal_Daily"
$t.Triggers[0].StartBoundary = "2026-01-01T21:00:00+08:00"   # 改成你要的北京时间
Set-ScheduledTask -InputObject $t
```

**查看/手动触发一次**：
```powershell
Get-ScheduledTask -TaskName "US_Trend_Signal_Daily"          # 看状态
Start-ScheduledTask -TaskName "US_Trend_Signal_Daily"        # 手动跑一次
```

## 二、手动运行（三种方式）

| 方式 | 命令 / 操作 | 说明 |
|------|-------------|------|
| 双击 | 双击 `每日信号.bat` | 窗口会停住显示结果，按任意键关闭 |
| 强制发信 | 双击 `强制发送.bat` | 无视交易日/窗口，立刻发一封（用于测试或补发）|
| 命令行 | 见下方 | 可加参数 |

命令行常用参数（传给 `signal\daily_signal.py`）：

```bat
每日信号.bat                      :: 正常跑一次（自动判断是否该发）
每日信号.bat --force             :: 无视交易日/窗口，照常发信（等价强制发送.bat）
每日信号.bat --dry-run           :: 只打印、不发信（看今天信号长啥样）
每日信号.bat --no-fetch          :: 用本地缓存数据，不联网拉新行情
每日信号.bat --force --dry-run   :: 强制 + 只打印（最安全的测试组合）
```

> 注意：bat 里的 `--quiet` 是给计划任务用的（跑完不弹窗等待）；手动双击不要加它。

    "skip_us_holiday": true
  }

- **总资金 `capital`**：当前 1000 U，5 只等权 → 每只 200 U。改这里即改每只仓位。
- **标的 `symbols`**：想换股票就改列表（美股代码，大写）。
- **均线 `ma`**：默认 200 日。
- **大盘牛熊开关 `market_filter`**：`enabled=true` 时，SPY 跌破 MA200 → 全部清仓持币（不做空）；设 `false` 则退回纯多（不理大盘）。
- **邮箱 `mail`**：发件箱/收件箱/授权码。163 邮箱的 `password` 是**授权码**不是登录密码。

## 五、信号规则与回测结论（给你吃个定心丸）

**规则很简单**：
1. 每只标的，当天收盘价比 200 日均线高 → 次日开盘买入并持有；跌破均线 → 次日开盘清空。5 只等权，互不影响。
2. **大盘牛熊开关**：SPY 收盘跌破自己的 MA200 → 不管个股信号如何，全部清仓持币（不做空）；SPY 重新站上 MA200 → 恢复按个股信号做多。

**回测数字（2002-05 ~ 2026-10，24.4 年，东财后复权）**：

| 策略 | 总倍数 | 年化 | 最大回撤 | Calmar |
|------|--------|------|----------|--------|
| **最终策略（做多5只 + 大盘熊清仓）** | **1145x** | **33.5%** | **−16.8%** | **1.99** |
| 纯多（不理大盘）| 322.7x | 26.8% | −29.6% | 0.90 |
| 买入持有 | 847.2x | 31.9% | −57.7% | 0.55 |

加了「大盘牛熊开关」后，收益更高、回撤砍到只剩买入持有的三分之一，Calmar 从 0.90 提到 **1.99**。

**熊市段表现（最终策略 / 纯多 / 买入持有）**：
- 科网崩盘 2000–2002：**0.0%** / −7.1% / −28.7%
- 金融危机 2007–2009：**+20.1%** / −9.0% / −18.7%
- 疫情崩盘 2020-02~03：**+1.6%** / −26.9% / −20.0%
- 加息熊市 2021–2022：**+4.1%** / −15.0% / −35.7%

详见 `报告\美股趋势_最终策略.html`（含曲线图）。

> 一句话：这策略用「个股跌破 200 日线就走」+「大盘跌破 200 日线全撤」给自己装了双保险。牛市满仓吃涨，系统性熊市直接空仓躲开，比死拿少亏很多；代价是震荡市会反复打脸、慢牛里略跑输买入持有。

**为什么不做空？** 实测「跌破就裸空」和「SPY 熊时全空」都很差（Calmar 0.28 / −0.06），会被反弹逼空。对这 5 只成长龙头，**空仓持币才是最稳的防守**。详见 `报告\美股趋势_多空结合验证.html`、`报告\美股趋势_做空时机探索.html`。

## 七、踩过的坑（排错用）

1. **中文计算机名导致发信崩溃**：本机 hostname 是中文，`smtplib` 的 EHLO 会 `UnicodeEncodeError`。已用 `SMTP_SSL(..., local_hostname="localhost")` 解决，不用动。
2. **东财接口偶发封 IP**：本机 IP 曾被 `push2his.eastmoney.com` 拉黑。每日信号主源已切到**新浪美股**，东财仅作备用；熊市检验用的是本地 `backtest\data\em\` 缓存，不联网，不受影响。
3. **新浪数据有拆股跳变**：用「开盘价/前一日收盘」判据识别拆股（NVDA 2024-06 10:1、NFLX 2025-11 10:1 等），避免误判成暴跌。
4. **东财后复权有接缝**：AAPL 2005-01-03、NFLX 2004-02-12 有因子切换跳变，已用比例缩放修正（保住 2000 年起的历史）。
5. **bat 互相 call 中文文件名会失败**：所以 `每日信号.bat` 和 `强制发送.bat` 是**各自独立完整路径**写的，不要用 `call` 去串它们。

## 八、日志与排查

- 运行日志：`signal\logs\` 下按日期存。
- 今天没收到邮件？先看：
  1. 是不是周末/美国节假日（本来就不发）；
  2. 北京时间是否不在 20:30 触发的那一天（看计划任务上次运行结果）；
  3. `signal\logs\` 里有没有报错（多半是网络/邮箱授权码）。
- 想立刻验证邮件能不能发：双击 `强制发送.bat`，能收到就说明链路通。
