五、DOGE 为什么不行

DOGE 是这套策略唯一明显失效的标的，原因值得单独说明：
  • 回撤几乎没改善：策略 87.2% vs 买入持有 92.3%，只降了 5 个百分点。
  • 胜率仅 15.9%：44 笔交易只有 7 笔盈利。最大连续亏损 19 笔——几乎不可能有人扛得住。
  • 盈亏比只有 1.17（BTC 是 2.81）。
  • 收益全靠一波：2021 年 +4967%（DOGE 从 $0.005 涨到 $0.74），但随后 2022 −39%、2023 −31%、2025 −72%。
根本原因：DOGE 是纯情绪驱动的 meme 币，价格在极短时间内暴涨暴跌，而 EMA200 和 MACD 本质是滞后指标—— 等它们确认趋势时，行情已经走完大半；等它们确认破位时，已经跌掉一大截。在 DOGE 这种波动结构上，趋势跟随的滞后代价超过了它避开熊市的收益。

建议：不要把这套策略用在 DOGE 这类高波动 meme 币上。如果一定要用，只能考虑更快的均线（EMA100 在 DOGE 上 Calmar 0.90 vs EMA200 的 0.70），但要接受 84% 的回撤。

六、回测可信度审计

回测最容易骗人的地方是偷看未来数据。这里用独立方法验证：绕开回测引擎， 用同一个 regime_on() 函数逐日重算状态序列，再与回测产出的交易记录逐笔比对。 如果两者吻合，说明回测没有作弊。

6.2 执行约定（回测 = 实盘）

项目约定
信号确认第 i 根 K 线收盘后计算 EMA200 与 MACD
入场成交第 i+1 根开盘价 × (1 + 0.05% 滑点)
离场成交第 i+1 根开盘价 × (1 − 0.05% 滑点)
唯一例外黑天鹅硬止损是挂单，价格日内触及即成交（真实可执行，故不计入信号点）

全部交易的成交日 = 信号确认日的次日，无一例外。买入价严格等于当日开盘价 × 1.0005，卖出价 × 0.9995。

审计中发现并修正的问题：初版回测的离场曾用「当根收盘价」成交——这是真实的前视偏差， 因为收盘价是当天最后一笔成交价，你在收盘前无法知道它。修正为「次日开盘成交」后， BTC 年化从 38.3% 变为 38.2%（影响很小，说明原结论依然成立），但方法上现在是严格无偏的。

七、脚本用法

脚本：macdx_strategy.py（单文件、纯标准库、无需安装任何依赖，Python 3.8+）

# 回测默认 4 个标的（自动联网下载数据）
python macdx_strategy.py

# 只回测指定标的
python macdx_strategy.py --symbols BTCUSDT ETHUSDT

# 4 小时周期
python macdx_strategy.py --symbol BTCUSDT --interval 4h

# 只看当前该持仓还是空仓（实盘用）
python macdx_strategy.py --symbol BTCUSDT --signal

# 用本地缓存数据，不联网
python macdx_strategy.py --no-fetch

# 调整参数
python macdx_strategy.py --trend-ema 150 --confirm 2

数据会缓存到 data/ 目录。首次运行需要联网。

八、策略规则速查

项目规则
入场收盘价 > EMA(200) 且 MACD 快线 > 0　→　次日开盘买入
出场收盘价 < EMA(200) 或 MACD 快线 < 0　→　次日开盘卖出
硬止损跌破入场价 −35%（历史回测从未触发，纯黑天鹅保险）
仓位满仓进出（实盘建议单标的 50%~70%）
交易频率年均约 4 笔，不需要盯盘
不做的事不做常规止盈、不做追踪止损、不做崩盘保护——回测证明这三项都在损害收益
风险提示：以上全部是历史回测结果。BTC/ETH/DOGE/SOL 的样本期恰好是加密市场史上最强的一轮牛市， 任何长期持有多头策略在此样本上都会显得很好。策略没有做空能力，空仓是它的极限防守。 若未来市场长期横盘或下跌，策略会持续小亏。本报告仅供研究，不构成投资建议。
