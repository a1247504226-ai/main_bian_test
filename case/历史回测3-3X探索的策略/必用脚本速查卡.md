# 必用脚本速查卡

> 打印或截图存手机。**只有 6 个 `.bat` 需要你双击**，其余全是它们调用的零件。

---

## 你只需要点这 6 个

| 脚本 | 什么时候点 | 会下单吗 |
|---|---|---|
| **`run_all.bat`** | ★ 每天（或让定时任务跑） | ❌ 永不 |
| **`run_switch.bat`** | ★ 想切换「只推送 ⇄ 真下单」 | ⚠️ 选 ON 后，下次跑 `run_trade.bat` 才会 |
| **`run_status.bat`** | 想知道现在什么状态、该下多少 | ❌ 永不 |
| `run_sync_check.bat` | 实盘前 / 每月检查 | ❌ 永不 |
| `run_trade.bat` | 手动执行一次下单 | ✅ 开关打开时才会 |
| `run_alert.bat` | 每小时跑（止损/爆仓提醒） | ❌ 永不 |

---

## 三个开关字段（`config.json` 顶部）

```json
"_master_switch": {
  "mode": "observe",                    ← observe = 只推送 | live = 真下单
  "i_understand_real_money": false      ← 必须同时为 true
}
```

| mode | confirm | 结果 |
|---|---|---|
| `observe` | 任意 | ✅ 只发邮件，绝不下单 |
| `live` | `false` | ⛔ 仍不下单，并报错提示 |
| `live` | `true` | ⚠️ 真实下单已放行 |

> 用 `run_switch.bat` 会自动把 `mode`、`i_understand_real_money`、
> `trade.dry_run` 三个字段一起设好，不用手动管。

## 想跑 A 档或 C 档？两个地方改

默认只跑 B 档，但 **A / B / C 三档一直都在**，随时可切：

### ① 邮件推送：跑哪几档

`run_all.bat` 一次推**全部三档**（A+B+C 合并一封邮件），不用改配置。
想只看某一档，用独立入口（在 `live\` 目录里跑）：

| 命令 | 效果 |
|---|---|
| `python run_all.py` | 三档合并一封邮件（默认，推荐） |
| `python strategy_a.py` | 只推 A 档 |
| `python strategy_b.py` | 只推 B 档 |
| `python strategy_c.py` | 只推 C 档 |

加 `--dry-run` 就是不发信只看结果。

### ② 自动下单：只跑哪一档

`config.json` → `trade.profile`，填 `"A"` / `"B"` / `"C"` 之一：

```json
"trade": {
  "profile": "B",      ← 改成 "A" 或 "C" 即可
```

**只能填一个**（原因：仓位按账户总余额算，跑两档会互相覆盖）。

### ③ 每档的参数都能改

```json
"profiles": {
  "A": { "name": "A 保守", "vol_target": 0.02, "equity": 10000.0 },
  "B": { "name": "B 推荐", "vol_target": 0.03, "equity": 10000.0 },
  "C": { "name": "C 激进", "vol_target": 0.05, "equity": 10000.0 }
}
```

| 字段 | 含义 | 怎么改 |
|---|---|---|
| `vol_target` | 目标日波动，**这就是风险旋钮** | 越大收益和回撤同比例放大。B 档 0.035 = 「比B激进比C温和」 |
| `equity` | 该档的本金基准 | 跑实盘时改成你实际投入的金额 |
| `name` | 邮件里显示的名字 | 随便改 |

**三档互相独立**：改 C 档不影响 A 档（已实测验证）。
改完存盘立即生效，下次跑就是新参数。

> ⚠️ 注意：实盘自动下单时，实际仓位按**交易所真实余额**自动缩放，
> `equity` 只是回测/邮件里的参照值。所以「想跑 X 档」真正决定风险的是 `vol_target`。

## 定时任务（管理员 PowerShell）

```powershell
$dir = "C:\Users\hongji\WorkBuddy AI\2026-09-29-21-48-51\btc_lev\live"

# 每天 08:01 发信号邮件（纯推送，永不下单）
schtasks /Create /TN "BTC_Signal_Push" /TR "`"$dir\run_all.bat`"" /SC DAILY /ST 08:01 /F

# 每小时检查风控位
schtasks /Create /TN "BTC_Price_Alert" /TR "`"$dir\run_alert.bat`"" /SC HOURLY /F

# 只在你想全自动下单时才加这条（08:05，在推送之后）
schtasks /Create /TN "BTC_Auto_Trade" /TR "`"$dir\run_trade.bat`"" /SC DAILY /ST 08:05 /F
```

查看 / 删除：

```powershell
schtasks /Query  /TN "BTC_Signal_Push"
schtasks /Delete /TN "BTC_Signal_Push" /F
```

## 上线四步

```
① run_sync_check.bat     → 看到「✓ 可以上线」
② run_trade.bat          → observe 模式下会拒绝，正常
③ run_switch.bat → ON → 输 YES
④ run_trade.bat          → 邮件里看到「✅ 已执行」即成功
```

**停下来**：`run_switch.bat` → OFF。
注意关开关 ≠ 平仓，已有持仓会保留。

## 出错先看这里

| 现象 | 处理 |
|---|---|
| 没收到邮件 | 查垃圾箱 → `run_all.py --test` → 看 `logs\live_ABC.log` |
| 报 `-2015` | API 的 IP 白名单失效，回币安后台更新你当前公网 IP |
| 报 `-1021` | 系统时间不准，开启自动同步 |
| 报「拒绝真实下单」 | 开关没开全，`run_switch.bat` 重新 ON |
| 报「发现未完成的意图」 | 上次下单可能中断。先 `run_sync_check.bat` 核对持仓，确认后加 `--force` |
| 下单失败 | **立刻登录币安人工核对持仓**，不要重复跑 |
