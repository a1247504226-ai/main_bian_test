# 必用脚本速查卡

> 打印或截图存手机。**只有 7 个 `.bat` 需要你双击**，其余全是它们调用的零件。

---

## 你只需要点这 7 个

| 脚本 | 什么时候点 | 会下单吗 |
|---|---|---|
| **`run_all.bat`** | ★ 每天（或让定时任务跑） | ❌ 永不 |
| **`install_tasks.bat`** | ★ 一次性建好 3 个定时任务（会自动提权） | ❌ 永不 |
| **`run_switch.bat`** | ★ 想切换「只推送 ⇄ 真下单」 | ⚠️ 选 ON 后，下次跑 `run_trade.bat` 才会 |
| **`run_status.bat`** | 想知道现在什么状态、该下多少 | ❌ 永不 |
| `run_sync_check.bat` | 实盘前 / 每月检查 | ❌ 永不 |
| `run_trade.bat` | 手动执行一次下单 | ✅ 开关打开时才会 |
| `run_alert.bat` | 每小时跑（止损/爆仓提醒） | ❌ 永不 |

`uninstall_tasks.bat` 用来删定时任务；`check_files.bat` 用来查文件有没有拷漏。

## 三个开关字段（`config.json` 顶部）

```json
"_master_switch": {
  "mode": "observe",                    ← observe = 只推送 | live = 真下单
  "i_understand_real_money": false      ← 必须同时为 true
}
```

| mode | confirm | 结果 |
|---|---|---|
| `observe` | 任意 | ✅ 只发邮件，绝不下单 |
| `live` | `false` | ⛔ 仍不下单，并报错提示 |
| `live` | `true` | ⚠️ 真实下单已放行 |

> 用 `run_switch.bat` 会自动把 `mode`、`i_understand_real_money`、
> `trade.dry_run` 三个字段一起设好，不用手动管。

## 对接币安，只有 3 件事要做

| # | 做什么 | 在哪做 |
|---|---|---|
| 1 | 创建 API Key（**只勾「允许合约」**，不勾提现/划转） | 币安 → API 管理 |
| 2 | 加 **IP 白名单** | 币安 → API 管理 → 编辑限制 |
| 3 | 账户改成 **「单向持仓」** 模式 | 币安 App → 合约 → 设置 → 持仓模式 |

然后把 Key / Secret 填进 `config.json` 的 `trade.apiKey` / `trade.apiSecret`。

> ⚠️ **第 3 条不做会直接报错**：本策略是单向净头寸，
> 双向持仓模式下同一交易对有多空两条持仓记录，仓位会算错，程序会拒绝运行。

> ⚠️ **第 2 条强烈建议做**：程序为兼容各种网络关闭了 HTTPS 证书校验，
> 加白名单后即使密钥泄露别人也用不了。

## 定时任务：不用手打命令

**双击 `install_tasks.bat`**（弹 UAC 点「是」），一次建好 3 个：

| 任务名 | 频率 | 跑什么 |
|---|---|---|
| `BTC_Signal_Push` | 每天 **08:05** | `run_daily.bat` — 推日报 |
| `BTC_Price_Alert` | **每小时** | `run_alert.bat` — 风控提醒 |
| `BTC_Auto_Trade` | 每天 **08:10** | `run_trade.bat` — 自动下单（默认空转） |

> `BTC_Auto_Trade` 装上是安全的：总开关还是 `observe` 时它什么都不做。

删除：双击 `uninstall_tasks.bat`。
查看：`schtasks /Query /TN "BTC_Signal_Push"`

## 想跑 A 档或 C 档？两个地方改

默认只跑 B 档，但 **A / B / C 三档一直都在**，随时可切：

### ① 邮件推送：跑哪几档

`run_all.bat` 一次推**全部三档**（A+B+C 合并一封邮件），不用改配置。

| 命令 | 效果 |
|---|---|
| `run_all.bat` | 三档合并一封（默认，推荐） |
| `run_all.bat --daily` | 不管方向变没变，每天都发一封（定时任务用的就是这个） |

想只看某一档：在文件夹地址栏输 `cmd` 打开命令行，跑
`strategy_a.py` / `strategy_b.py` / `strategy_c.py`（需要 Python 在 PATH 里）。
**一般不需要这么做** —— 合并一封反而更好看，反正邮件里三档数字都列着。

### ② 自动下单：只跑哪一档

`config.json` → `trade.profile`，填 `"A"` / `"B"` / `"C"` 之一：

```json
"trade": {
  "profile": "B",      ← 改成 "A" 或 "C" 即可
```

**只能填一个**（原因：仓位按账户总余额算，跑两档会互相覆盖）。

### ③ 每档的参数都能改

```json
"profiles": {
  "A": { "name": "A 保守", "vol_target": 0.02, "equity": 1000.0 },
  "B": { "name": "B 推荐", "vol_target": 0.03, "equity": 1000.0 },
  "C": { "name": "C 激进", "vol_target": 0.05, "equity": 1000.0 }
}
```

| 字段 | 含义 | 怎么改 |
|---|---|---|
| `vol_target` | 目标日波动，**这就是风险旋钮** | 越大收益和回撤同比例放大。B 档 0.035 = 「比B激进比C温和」 |
| `equity` | 该档的本金基准 | **只影响邮件里显示的保证金/数量**，不影响实际下单 |
| `name` | 邮件里显示的名字 | 随便改 |

**三档互相独立**：改 C 档不影响 A 档（已实测验证）。改完存盘立即生效。

> ⚠️ 实盘自动下单时，实际仓位按**交易所真实余额**自动缩放。
> 所以「想降档」最直接的办法是**少放点钱进合约账户**，不用改配置。

## 常用命令行（不双击时用）

在文件夹地址栏输入 `cmd` 回车，就能在这里打开命令行：

```bash
run_all.bat --dry-run      # 算信号，不发邮件
run_all.bat --test         # 发测试邮件
run_all.bat --force        # 强制发一封信号邮件
run_trade.bat --check      # 只读对账，不下单
run_trade.bat --dry-run    # 预演下单
run_alert.bat --dry-run    # 看风控是否触发
```

## 上线四步

```
① run_sync_check.bat     → 看到「✓ 可以上线」
② run_trade.bat --dry-run → 看目标仓位对不对
③ run_switch.bat → ON → 输 YES
④ run_trade.bat          → 邮件里看到「已执行」即成功
```

**停下来**：`run_switch.bat` → OFF。
注意关开关 ≠ 平仓，已有持仓会保留。

## 出错先看这里

| 现象 | 处理 |
|---|---|
| 没收到邮件 | 查垃圾箱 → `run_all.bat --test` → 看 `logs\live_ABC_*.log` |
| 报「账户当前是双向持仓模式」 | 币安 App → 合约 → 设置 → 持仓模式 → 单向持仓 |
| 报 `-2015` | API 的 IP 白名单失效，回币安后台更新你当前公网 IP |
| 报 `-1021` | 系统时间不准，开启自动同步 |
| 报 `-2019` | 可用保证金不足，降低下单名义或加钱 |
| 报「拒绝真实下单」 | 开关没开全，`run_switch.bat` 重新 ON |
| 报「发现未完成的意图」 | 上次下单可能中断。先 `run_sync_check.bat` 核对持仓，确认后加 `--force` |
| 下单失败 | **立刻登录币安人工核对持仓**，不要重复跑 |
