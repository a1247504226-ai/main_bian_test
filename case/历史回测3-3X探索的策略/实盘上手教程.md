# 上手教程 · B 档实盘

> 目标：**先只收邮件、不下单**，观察一段时间后再决定是否让程序自动下单。
> 全程只需动一个配置项。所有脚本都在 `btc_lev\live\` 目录下。

## 第 2 步：设成每天自动推送

日线在 **UTC 00:00 收盘 = 北京时间 08:00**。
所以定时任务要设在 **08:01 或之后**（让币安那边的新 K 线先收盘）。

**以管理员身份**打开 PowerShell，粘贴运行：

```powershell
$dir = "C:\Users\hongji\WorkBuddy AI\2026-09-29-21-48-51\btc_lev\live"

# 每天 08:01 推送信号
schtasks /Create /TN "BTC_Signal_Push" /TR "`"$dir\run_all.bat`"" /SC DAILY /ST 08:01 /F

# 每小时检查风控位（止损/爆仓提醒）
schtasks /Create /TN "BTC_Price_Alert" /TR "`"$dir\run_alert.bat`"" /SC HOURLY /F
```

验证一下建好了没：

```powershell
schtasks /Query /TN "BTC_Signal_Push"
```

想删掉：

```powershell
schtasks /Delete /TN "BTC_Signal_Push" /F
```

> **重要**：`run_all.bat` 永远不会下单，它只发邮件。
> 下单是 `run_trade.bat` 的事，默认关闭。

```

==================================================

  数量：0.128791 BTC　占用保证金：3,628 USDT　杠杆：3× 逐仓
  参数明细：8/24→多　10/30→多　12/36→多　15/45→多　20/60→多

     爆仓价：56,768（距现价 -32.8%，这是 3× 逐仓的硬底）

**你只需要看这几行：**

| 看什么 | 意思 |
|---|---|
| 标题「方向变化」 | 只有**方向变了**才发信。没变化就不发，别以为程序挂了 |
| `▌操作清单` | ★ 这就是你要在币安做的事，照抄即可 |
| `占用保证金` | 在币安下单时，这笔单实际锁住多少钱 |
| `数量 ... BTC` | 填进委托数量框的数字 |
| `爆仓价` | 3× 逐仓固定距现价 -32.8%，跌到这里全部保证金没了 |

**收不到信就是没有信号。** 东八区早上 8 点后没收到，就是方向没变。

## 第 4 步：观察期（现在开始做）

**这一步什么都不用改，默认就是对的。**

确认一下开关状态，双击 **`run_status.bat`**，看第 1 段：

```
== 1. 总开关 ==========================================================
  当前模式        : observe
  真实下单        : ✓ 关闭（只推送信号，安全）
  只跑档位        : B（B 推荐）
```

看到 `observe` + `✓ 关闭` 就对了。

**观察期要观察什么：**

1. **邮件是否准时**（每天 08:01 后）；连续 5~7 天不迟到就算稳
2. **信号是否合理**（方向和自己看盘的感觉大致吻合）
3. **自己能否守住纪律**——这是关键。看到浮亏时有没有想手动砍？
4. 可以对着 `run_status.bat` 输出的「目标持仓」，在币安**手动**下一两笔小额单，
   练一下流程（比如先操作 1000 U）

> 观察期建议 **至少 2 周**，且必须**经历一次完整的方向反转**。

## 第 5 步：准备实盘（加白名单 + 填密钥）

### 5.1 创建币安 API 密钥

登录币安 → 头像 → **API 管理** → 创建 API → 选择 **系统生成**

- **权限**：只勾 **「允许合约」**（Enable Futures）
- **不要勾**：提现（Withdraw）、划转（Transfer）
- IP 白名单：稍后填（见 5.2）

创建后会给你 **API Key** 和 **Secret Key**，Secret **只显示一次**，先复制保存好。

### 5.2 加 IP 白名单

币安 → API 管理 → 找到刚建的那个 Key → **编辑限制** → **限制访问 IP**。

填你的公网出口 IP。查法：浏览器搜索「我的 IP」，或在 PowerShell 里跑：

```powershell
(Invoke-RestMethod "https://api.ipify.org?format=json").ip
```

> **注意**：填的是**你电脑的公网 IP**。
> 家庭宽带 IP 可能变化，变了就要回来更新，否则下单会报 `-2015` 错误。

### 5.3 填进配置

编辑 `live\config.json`，找到 `trade` 段：

```json
"apiKey": "在这里填你的币安API Key",
"apiSecret": "在这里填你的币安API Secret",
```

替换成真实密钥（保留引号）。

> **更安全的做法**：不写文件，改用环境变量。程序会优先读环境变量。
> ```powershell
> setx BINANCE_API_KEY "你的Key"
> setx BINANCE_API_SECRET "你的Secret"
> ```
> 设完要**重开一个命令行窗口**才生效。

## 第 6 步：检查账户连接（只读，不下单）

双击 **`run_sync_check.bat`**。

它会做 8 项检查，**全程只读、绝不下单**：

```
0. 总开关状态
1. 密钥
2. 时间同步
3. 账户余额
4. 合约钱包余额
5. 持仓
6. 交易对精度
7. 杠杆设置
8. 目标仓位差异
```

**重点是最后一行结论：**

- 出现 `✓ 可以上线` → 一切正常
- 出现 `✗` 或 `问题` → 按它给的提示修，别急着往下走

常见报错对照：

| 报错 | 原因 | 解决 |
|---|---|---|
| `-2015` | Key 无效 / IP 不在白名单 / 没开合约权限 | 回去查 5.1 和 5.2 |
| `-1021` | 本机时间和币安服务器偏差大 | 系统设置 → 时间 → 自动同步 |
| `-2019` | 可用保证金不足 | 降低下单名义，或加钱 |

## 第 8 步：开启实盘

### 8.1 先小额

建议第一次只放 **1000~5000 U** 进合约账户，跑一两个月。

> 记住：仓位是按**账户余额**自动缩放的。
> 放 5000 U 就等于在用 5000 U 的本金跑 B 档，
> 和「10 万本金只放 5 万进去」是**完全等价**的（本质是降档）。

### 8.2 打开开关

双击 **`run_switch.bat`** → 选 **3 (ON)** → 输入大写 **`YES`** 确认。

它会自动设置三个字段：

```json
"_master_switch": { "mode": "live", "i_understand_real_money": true },
"trade": { "enabled": true, "dry_run": false }
```

### 8.3 真跑第一次

双击 **`run_trade.bat`**。它会：

1. 拉最新已收盘 K 线 → 算信号
2. 连币安 → 读余额和持仓
3. 按余额算出目标仓位 → 和实际持仓比对
4. 有偏差就下单，然后发一封「已执行」邮件

**看到邮件里写着「✅ 已执行」就算成功了。**

### 8.4 设成每日自动下单（可选）

如果你希望完全自动，再加一个定时任务：

```powershell
$dir = "C:\Users\hongji\WorkBuddy AI\2026-09-29-21-48-51\btc_lev\live"
schtasks /Create /TN "BTC_Auto_Trade" /TR "`"$dir\run_trade.bat`"" /SC DAILY /ST 08:05 /F
```

> 08:05 在信号推送（08:01）之后 4 分钟，避免同时跑抢日志文件。

**但建议先手动跑 1~2 周**，确认每次动作都符合预期，再交给定时任务。

## 第 9 步：怎么停下来

**随时可以停，两个办法：**

1. **一键关**：双击 `run_switch.bat` → 选 **2 (OFF)**
2. **手改**：`config.json` 里 `_master_switch.mode` 改回 `"observe"`

**关掉后会发生什么：**

- ✅ 邮件推送继续（`run_all.bat` 不受影响）
- ✅ 已开的仓位**保持不动**（程序不会帮你平仓）
- ⛔ 不会再有新的下单动作

> **注意**：关开关 ≠ 平仓。
> 如果你关闭时还有持仓，需要自己决定是继续持有还是手动平掉。
> 程序的设计哲学是「跟着趋势走」，所以关掉自动下单后，
> 那个仓位就脱离策略管理了——**建议要么开着，要么手动全平**。

| 时间 | 动作 |
|---|---|
| 早上看邮件 | 有「方向变化」才需要动手；没有就什么都不做 |
| 每周一次 | 双击 `run_status.bat` 确认开关状态没被误改 |
| 每月一次 | 双击 `run_sync_check.bat` 确认账户连接正常 |

**其他时间不要打开看盘。** 回测里所有收益的前提都是
「按信号执行、中途不动手」。看得越勤，越容易破坏它。

## 必须知道的几件事

### 1. 不会爆仓，但会腰斩

3× 逐仓的爆仓距离是 **-32.8%**，而策略在触及爆仓前早就反向开仓了。
9 年回测（含手续费/滑点/资金费）**爆仓 0 次**。

但 B 档单次最大回撤是 **-50.3%**：
10 万本金最惨时剩 **4.97 万**，需要涨 **101%** 才能回本。
历史上最深的这次发生在 **2017-12-16 → 2018-11-07，持续 326 天**。

**这不是小概率事件。** 你要在开户前就想清楚：能不能扛住，能不能不手动砍。

### 2. 保证金占用是浮动的

保证金 =（目标波动 ÷ 日波动）÷ 3。所以：

| 档 | 中位 | 90% 分位 | 历史最高 |
|---|---|---|---|
| B | 23.6% | 37.1% | 57.9% |

行情平静时会占用更多，动荡时自动缩仓。
**账户里要留够钱**，否则会因为「可用保证金不足」下单失败。

### 3. A / B / C 三档都在，随时可切

**邮件推送**：`run_all.bat` 一次推**全部三档**（合并一封邮件），不用改配置。
想只看某一档，用独立入口：

| 命令 | 效果 |
|---|---|
| `python run_all.py` | 三档合并一封（默认，推荐） |
| `python strategy_a.py` | 只推 A 档 |
| `python strategy_b.py` | 只推 B 档 |
| `python strategy_c.py` | 只推 C 档 |

**自动下单**：`config.json` → `trade.profile`，填 `"A"` / `"B"` / `"C"` 之一。
现在默认是 `"B"`。

**只能填一个档位。** 跑两个会互相覆盖仓位（都是按账户总余额算的）。
想同时跑两档需要独立子账户——但对个人资金来说没有意义，
因为 B 和 C 的相关系数是 **0.99**，同时跑两档等同于跑一个中间档。

**每档参数都能改**（三档互相独立，改一个不影响另一个）：

```json
"profiles": {
  "A": { "vol_target": 0.02, "equity": 10000.0 },   ← 想调风险就改这里
  "B": { "vol_target": 0.03, "equity": 10000.0 },
  "C": { "vol_target": 0.05, "equity": 10000.0 }
}
```

`vol_target` 就是风险旋钮——想「比 B 激进、比 C 温和」就把 B 改成 `0.035`，
不用去配两个档位。

### 4. 幂等保护

同一天同一方向只会下单一次。如果程序中途崩了重启，不会重复下单。
看到日志说「幂等命中……跳过」是正常保护，不是故障。

### 5. 日志在哪

`logs\` 目录。出任何问题，先看当天的日志。

| 文件 | 内容 |
|---|---|
| `logs\live_ABC.log` | 信号推送日志 |
| `logs\trade.log` | 下单日志 |
| `logs\sync_check.log` | 对账日志 |
| `logs\alert.log` | 风控提醒日志 |

## 出问题了怎么办

| 现象 | 处理 |
|---|---|
| 没收到邮件 | 先查垃圾箱；再跑 `run_all.py --test` 测通道；再看 `logs\live_ABC.log` |
| `run_trade.bat` 说「尚未配置密钥」 | 回到第 5.3 步填 `config.json` |
| 报 `-2015` | IP 变了，回第 5.2 步更新白名单 |
| 报「拒绝真实下单」 | 开关没开全，双击 `run_switch.bat` 重新 ON |
| 报「发现未完成的意图」 | 上次下单可能中断了。先跑 `run_sync_check.bat` 人工核对持仓，确认无误后加 `--force` |
| 下单失败但邮件说失败 | **立刻登录币安人工核对持仓**，别重复跑 |
| 想确认到底下没下 | 跑 `run_status.bat`，看第 4 段「持仓对照」 |

## 一句话总结

1. 双击 `run_all.bat` → 收邮件（现在就可以开始）
2. 设个 08:01 的定时任务 → 自动推送
3. 观察 2 周以上，手动小额练手
4. 加 IP 白名单 + 填密钥 + 跑 `run_sync_check.bat`
5. 小额入金 → `run_switch.bat` 选 ON → 开跑
6. 想停就 `run_switch.bat` 选 OFF

**全程只有一个开关需要你操心。其余交给脚本。**
