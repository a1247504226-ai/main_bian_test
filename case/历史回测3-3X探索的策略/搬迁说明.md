# 搬迁说明 —— 把这套系统搬到另一台电脑（Windows）

> 你遇到的报错 `The system cannot find the path specified` + `can't open file '...\run_all.py'`，原因是：
> **只拷了 `.bat` 文件和文档，没拷 Python 脚本。** `.bat` 只是「启动器」，真正干活的是 `.py` 文件。

---

## 一、一句话结论

**把 `分发包_btc_lev_live` 这个文件夹【整个】拷过去，双击里面的 `.bat` 就能跑。**

不要只挑 `.bat` 出来拷。`.bat` 离了 `.py` 就是个空壳。

---

## 二、要拷贝什么

把下面这个文件夹**整包**复制到目标电脑（U 盘 / 微信传文件 / 网盘都行）：

```
分发包_btc_lev_live\
├── alert.py            ← 邮件推送
├── binance.py          ← 币安 API 封装
├── common.py           ← 核心：信号计算 + 配置读取 + 下单
├── config.json         ← 【唯一需要你改的文件】总开关 + API 密钥
├── run_all.py          ← A/B/C 三档一起跑
├── status.py           ← 一屏总览
├── strategy_a.py       ← A 档入口
├── strategy_b.py       ← B 档入口
├── strategy_c.py       ← C 档入口
├── sync_check.py       ← 与币安账户对账
├── trade.py            ← 自动下单
├── verify_live.py      ← 环境自检
├── logs\               ← 日志目录（空的，运行后自动写）
│
├── run_all.bat         ← 双击：跑三档信号 + 推邮件（最常用）
├── run_status.bat      ← 双击：一屏总览，看当前信号和仓位
├── run_switch.bat      ← 双击：菜单式开关管理（改档位 / 开实盘）
├── run_trade.bat       ← 双击：自动下单（观察期不会真下单）
├── run_sync_check.bat  ← 双击：跟币安账户对账
├── run_alert.bat       ← 双击：只推一封测试邮件
└── run_daily.bat       ← 给「计划任务」用的每日版本
```

**共 11 个 `.py` + 1 个 `config.json` + 7 个 `.bat` + 1 个 `logs` 空目录。**

## 三、目标电脑的前提条件

| 项目 | 要求 | 怎么检查 |
|---|---|---|
| 操作系统 | Windows 10 / 11 | —— |
| Python | **3.8 或更高**（推荐 3.11+） | 打开 cmd，敲 `python --version` |
| 网络 | 能访问币安 + 163 邮箱 | 普通家宽即可 |
| （实盘才需要）币安 API | Key/Secret + 本机 IP 白名单 | 见教程第 6 步 |

### 没装 Python 怎么办

到 https://www.python.org/downloads/ 下载最新的 Windows 安装包，**安装时务必勾选 `Add Python to PATH`**（在最下面那行，很容易漏）。

装完重开一个 cmd 窗口，敲 `python --version`，能打出 `Python 3.1x.x` 就成。

> 我们的 `.bat` 会自动去这些地方找 Python，找到哪个用哪个：
> 1. 原电脑的托管 Python 路径（搬过去后一般不存在，会自动跳过）
> 2. `%LOCALAPPDATA%\Programs\Python\Python313 / 312 / 311 / 310`
> 3. `C:\Python313 / 312 / 311`
> 4. 系统 PATH 里的 `python`
> 5. 系统 PATH 里的 `py`（Python Launcher）
>
> 全都没找到时，会明确提示 `[ERROR] Python not found`，不会莫名其妙闪退。

## 四、搬迁后的操作步骤（4 步）

### 第 1 步：确认文件齐全

双击 `run_all.bat`。

- ✅ 如果打印出 A / B / C 三档的信号和价格 → 文件齐全，Python 也认到了，搞定。
- ❌ 如果提示：
  ```
  [ERROR] run_all.py not found in this folder:
          C:\...\你的目录
   You must copy ALL files from the live folder, not just the .bat files.
  ```
  → 说明你又是只拷了 `.bat`，把 `.py` 也拷过来。
- ❌ 如果提示 `[ERROR] Python not found` → 回到上一节装 Python。

### 第 2 步：改配置（可选，但建议看一眼）

用记事本打开 `config.json`，**只需要看文件最上面那段**：

```json
"_master_switch": {
    "mode": "observe",
    "i_understand_real_money": false
}
```

- `mode: "observe"` → **只推送，不下单**（默认，安全，先这么跑）
- `i_understand_real_money: false` → 双保险，防止误改

**新电脑上第一次跑，先保持 `observe` + `false` 不动，观察几天。**

### 第 3 步：测试邮件

双击 `run_alert.bat`，去 `1247504226@qq.com` 收信。收到说明推送链路通了。

### 第 4 步：设置每日定时任务（可选）

想让电脑每天自动跑一次、自动推邮件，用 Windows「任务计划程序」：

1. Win 键搜「任务计划程序」打开
2. 右侧「创建基本任务」
3. 名称填 `BTC信号推送`
4. 触发器：每天，时间填 **08:05**（BTC 日线 08:00 收盘，5 分钟后跑最稳）
5. 操作：启动程序 → 程序填 `run_daily.bat` 的**完整路径**（在「起始于」里填该文件夹路径）
6. 完成

> 更详细的图文步骤见同目录《实盘上手教程.md》第 3 步。

## 五、常见报错对照表

| 报错 | 原因 | 解决 |
|---|---|---|
| `The system cannot find the path specified` | 旧版 bat 写死了原电脑的路径 | 本包已修复（用 `%~dp0` 自适应），用本包的 bat |
| `can't open file '...run_all.py': [Errno 2] No such file` | 没拷 `.py` 文件 | 把 `.py` 一起拷过来 |
| `[ERROR] Python not found` | 目标电脑没装 Python | 装 Python 并勾 PATH |
| `python 不是内部或外部命令` | 装了但没勾 Add to PATH | 重装并勾选，或改用 `py` |
| 邮件收不到 | 163 授权码失效 / 进了垃圾箱 | 检查邮箱垃圾箱；重新申请授权码填进 `config.json` 的 `email` 段 |
| 币安连接失败 | 网络 / IP 不在白名单 | 先用 `run_status.bat --offline` 只算信号；实盘前再把 IP 加白名单 |
| 中文显示成乱码 | 终端编码问题 | 我们的 bat 已带 `chcp 65001`，用本包的 bat 即可 |
