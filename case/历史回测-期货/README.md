# 中国商品期货日线趋势策略 —— 研究工具

一个不依赖任何付费数据的商品期货策略研究框架：拉数据 → 修正数据 → 扫描信号 →
参数寻优 → 严格校验 → 生成报告。

```bash
python ft.py check        # 数据体检：换月跳空诊断
python ft.py scan         # 14 类信号族全样本扫描
python ft.py bias         # 随机信号控制实验：量化残余漂移
python ft.py explore      # 成本敏感性 / 参数寻优 / 样本内外秩相关
python ft.py bench        # 基准对照：买入持有 / 截面动量反转 / 波动率 / 止损
python ft.py surface      # (快线,慢线) × 止损 参数曲面
python ft.py validate 时序动量250   # 完整校验（可指定任意信号）
python ft.py rank         # 逐品种归因：最终策略单独跑每个品种，排出收益最高的品种
python ft.py report       # 生成单文件 HTML 报告

python strategy_top2.py            # 打印今天的信号 + 跑回测
python strategy_top2.py signal     # 只打印今天的信号（不发邮件）
python strategy_top2.py notify     # 检查信号变动，有变动就发邮件（定时任务调用）
python strategy_top2.py backtest   # 只跑回测
python strategy_top2.py refresh    # 只更新行情数据
python strategy_top2.py test-mail  # 发一封样例邮件，验证邮箱配置
```

环境变量 `FT_RAW=1` 可切回**未复权**主连序列，用于对照实验。

---

## 最重要的发现：主连不是可回测序列

新浪"主连"是主力合约的**不复权拼接**。换月当天价格直接跳到新合约价位，
产生一次跳空。**这个跳空不是交易者能拿到的盈亏。**

算例：近月 100、远月 105（contango）。

| | 原始主连 | 真实持仓 |
|---|---|---|
| 换月当天 | 100 → 105，记 +5% | 卖 100 的合约、买 105 的合约，损益 0 |
| 换月之后 | 新合约从 105 向现货收敛 | 同左，**亏 5%** |
| 一轮净结果 | **+0%**（跳空被记成盈利） | **−5%** |

原始序列把"亏损"记成了"盈利"。后果是毁灭性的：

| 信号 | 原始主连 | 复权后 |
|---|---|---|
| 截面动量 N=250 | **−22.8%** | **+12.8%** |
| 截面反转 N=250 | **+6.4%** | **−23.5%** |

**符号完全对调。** 这解释了为什么大量用主连做的回测会得出
"中国商品期货动量失效、是反转市场"的错误结论。

`ft.py` 的 `_adjust()` 做**比例复权**：把换月日整根 K 线乘以累计因子
`k *= 前收/今开`，使复权后 open 与前收严丝合缝，日内涨跌幅不变，
累计因子只依赖当日及此前的换月，**不含未来信息**。

数据体检实测：43 个品种中 **34 个**换月跳空累计为正，中位 **+48.7%**。

## 复权后的真实图景

41 品种等权 · 2009–2026 · 2bp 手续费 + 5bp 滑点（单边）· 多空对称口径

| 信号 | 年化 | 最大回撤 | Calmar | Sharpe | 只多 | 只空 |
|---|---|---|---|---|---|---|
| 时序动量250 | **+3.7%** | 20.2% | 0.18 | 0.46 | 3.3% | 0.1% |
| 双均线40/120 | +2.5% | 26.6% | 0.09 | 0.33 | 3.0% | −0.7% |
| 唐奇安55 | +2.5% | 23.2% | 0.11 | 0.31 | 2.7% | −0.4% |
| 双均线20/60 | +2.4% | 23.2% | 0.10 | 0.30 | 2.7% | −0.5% |
| 均线+唐奇安 | +2.1% | 21.3% | 0.10 | 0.28 | 2.3% | −0.3% |
| **展期收益carry** | +3.0% | **12.4%** | **0.24** | **0.62** | 3.1% | −0.3% |
| **carry+趋势** | +2.5% | **10.7%** | 0.23 | 0.59 | 2.0% | **+0.4%** |
| 波动突破 | −10.5% | 86.4% | −0.12 | −1.65 | −4.2% | −6.7% |
| 布林回归 | −5.7% | 67.3% | −0.08 | −0.76 | −2.3% | −3.5% |

**趋势类与展期收益为正，均值回归类与波动突破为负。**

### 推荐配置：carry+趋势

"展期结构"与"价格趋势"同向才持仓。

| 校验项 | 结果 |
|---|---|
| 多空对称年化 | +2.5%，回撤 10.7%，Sharpe 0.59 |
| 只空侧 | **+0.4%**（不依赖市场上涨，是真 edge） |
| 样本内 2009–2018 | +2.0% |
| 样本外 2019–2026 | **+3.1%**（外样本更好） |
| 分块自助 1000 次 | 90% 区间 [0.8%, 4.2%]，**年化为负概率仅 1.0%** |
| 5× 成本压力 | **+0.1%（仍为正）** |
| 逐年 | 17 年中仅 3 年为负，且幅度小 |

参数曲面（快线 × 慢线，无止损）是一整片 **+2% ~ +3.5% 的平台**，
无孤立尖峰 —— 稳健而非过拟合。

### 两条反直觉但稳健的结论

1. **日线硬止损是负贡献。** 止损越紧、整体越差（单调）。
   日线级别止损主要在震荡里反复砍仓。真正的保护来自**仓位**，不是止损线。
2. **降低换手不解决问题。** "低换手时序动量"反而比原版差，
   说明成本不是唯一瓶颈；但低换手信号（250 日动量、carry）确实成本占比最小。

## 逐品种归因：收益最高的品种 vs 2 万能做的品种

`python ft.py rank` 把 carry+趋势 单独跑在每个品种上（波动率目标 2%、无止损）：

| # | 品种 | 年化 | 回撤 | Calmar | 只多 | 只空 | 样本内 | 样本外 | 1手保证金 | 2万可行 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | LH 生猪 | +14.9% | 25.3% | 0.59 | −2.8% | **+18.2%** | — | +14.9% | 21,523 | **×** |
| 2 | J 焦炭 | +14.7% | 41.5% | 0.36 | +4.9% | +9.3% | +34.5% | **−2.0%** | 32,320 | **×** |
| 3 | FG 玻璃 | +11.4% | 29.2% | 0.39 | +8.4% | +2.8% | +10.3% | +12.4% | 2,267 | √ |
| 4 | I 铁矿石 | +10.5% | 31.1% | 0.34 | +10.7% | −0.2% | −3.1% | +20.7% | 9,555 | √ |
| 5 | RB 螺纹钢 | +10.2% | 38.7% | 0.26 | +3.6% | +6.3% | +14.8% | +4.7% | 3,388 | √ |
| 6 | NI 沪镍 | +9.1% | 16.5% | 0.55 | +8.2% | +0.9% | +5.7% | +10.9% | 19,056 | × |
| 7 | HC 热卷 | +9.1% | 22.3% | 0.41 | +8.4% | +0.6% | +5.9% | +11.1% | 3,581 | √ |

**收益前二（生猪 + 焦炭）合在一起：+20.0%/年、回撤 29.6%、Sharpe 1.09**
（多空对称口径）。但三个理由说明它不可用：

1. **2 万开不起。** 生猪 1 手保证金 ≈21,523 元（**已超过全部本金**），
   焦炭 ≈32,320 元。这不是"仓位小一点"，是根本下不了单。
2. **生猪只有 5.7 年数据**（2021-01 上市），且利润 **100% 来自做空**（只多 −2.8%），
   骑的是 2021 年至今的猪价单边熊市 —— 一次性行情，不是可重复的 edge。
3. **焦炭样本外衰减**：样本内 +34.5% → 样本外 −2.0%。

### 可落地组合：玻璃 FG + 热卷 HC

`strategy_top2.py` 默认就是这一组。2014-03 → 2026-10（12.5 年）：

| 指标 | auto 模式（默认） | fixed 1手/腿 |
|---|---|---|
| 年化 | **15.35%** | 14.75% |
| 期末权益 | 119,351（5.97x） | 111,900（5.60x） |
| 最大回撤 | **23.4%** | 26.0% |
| Calmar / Sharpe | 0.65 / 0.96 | 0.57 / 0.85 |
| 样本内 ≤2018 | 11.33% | 14.95% |
| 样本外 ≥2019 | **17.92%** | 14.63% |
| 1 手保证金 | 玻璃 2,267 + 热卷 3,581 ≈ 29% 权益 | 同左 |

**auto 模式**：手数 = 敞口 × (权益 / 同时持仓数) / 单手名义，随本金自动缩放，
所以会随盈利复利；**fixed 模式**：每腿恒定 1 手，杠杆随权益增长而稀释。

### 品种分层：本金涨了自动加品种

只改 `EQUITY` 一个数，`CAPITAL_TIERS` 里够门槛的品种会自动启用：

| 门槛 | 新增品种 | 1手保证金 | 该品种年化 / 只空年化 |
|---|---|---|---|
| 2万起 | 玻璃 FG、热卷 HC | 2,267 / 3,581 | 11.4% / +2.8%　9.1% / +0.6% |
| 3万起 | 螺纹钢 RB、纯碱 SA | 3,400 / 5,200 | 10.2% / +6.3%　4.9% / +0.7% |
| 6万起 | 短纤 PF、棉花 CF | 3,900 / 4,900 | 3.5% / +1.2%　3.5% / +1.9% |
| 11万起 | 沪镍 NI | 17,000 | 9.1% / +0.9%（Calmar 0.55 全场最高） |
| 16万起 | 焦煤 JM | 17,000 | 8.0% / +1.8% |
| 20万起 | 橡胶 RU | 17,000 | 4.5% / +2.0% |
| 29万起 | **焦炭 J** | 28,000 | **14.7% / +9.3%（全池最高）** |

**入池标准（这一版最关键的变化）**：只收「**只多、只空都为正**」的品种。
主连复权后仍残留约 +1.7%/年的真实现货升值，一个品种若「只空为负」，
它的收益全来自市场上涨，换个年份就没了；只有两侧都为正，
才说明 `carry + 趋势` 在该品种上是**可重复的 edge**。按此剔除：

| 剔除品种 | 年化 | 只空年化 | 原因 |
|---|---|---|---|
| 铁矿石 I | +10.5% | −0.2% | 收益靠漂移 |
| 尿素 UR | +4.2% | −0.1% | 收益靠漂移 |
| 豆粕 M | +2.5% | −3.1% | 收益靠漂移 |
| 玉米 C | −1.9% | −2.4% | 两侧皆负 |
| 菜粕 RM | −2.6% | −2.4% | 两侧皆负 |
| 玉米淀粉 CS | −2.7% | −0.6% | 两侧皆负 |
| 生猪 LH | +14.9% | **只多 −2.8%** | 单边押注猪价熊市，且仅 5.7 年数据 |

门槛 ≈ `MIN_FILL × 2 × 1手名义 / 敞口` —— 即「假设同时持有 2 个品种、
1 手至少覆盖该腿目标风险的 50%」所需权益。**收益最高的焦炭排在最后**，
因为它 1 手名义 20 万，账户不够大时 1 手就是十几倍杠杆。

### 一键运行与自动定时任务

| 文件 | 用途 |
|---|---|
| `一键运行.bat` | **双击即跑**。更新数据 → 比对信号 → 有变化发邮件。窗口保留不闪退。 |
| `安装定时任务.bat` | **右键「以管理员身份运行」**。注册 Windows 计划任务，工作日 16:00 自动跑。 |
| `卸载定时任务.bat` | 删除该计划任务。 |
| `task_run.bat` | 定时任务实际调用的静默版，输出追加到 `logs\auto.log`。 |

`.bat` 文件是 GBK 编码（Windows 中文默认），中文提示在 cmd 里显示正常。
脚本优先调用隔离环境里的 Python（`akshare 1.19.1`），找不到才退回系统 `python`。

### 邮件通知

`python strategy_top2.py notify` 会：
1. 先用 akshare 更新行情数据（`refresh`）
2. 比对 `signal_state.json` 里上次已通知的仓位
3. **只有信号真的变动（开仓/平仓/反手）才发邮件**；数据没更新或无变动则静默跳过

邮件正文是手机友好的 HTML 表格（`table-layout:fixed` + 固定列宽，
窄屏不会撑破），另有纯文本兜底。由 `安装定时任务.bat` 注册的
Windows 计划任务在工作日 16:00 自动调用（另有 WorkBuddy 定时任务 16:30 兜底）。

### 什么参数会触发推送

推送由「**信号变动**」触发，不是按时间无脑发。一次 `notify` 的判定链：

1. 用 akshare 刷新行情。若 `data_date` 与 `signal_state.json` 里记录的相同
   （当天数据还没更新）→ **直接静默退出，不发邮件**。
2. 否则用当日收盘数据重算每个品种的三条腿信号，与上次已通知的仓位比对。
3. 只有出现 **开多 / 开空 / 平仓 / 反手** 才发邮件；否则静默。
   （第一次运行没有历史状态，会发一封基线邮件。）

真正决定「有没有信号」的是这几个参数：

| 参数 | 默认 | 作用 |
|---|---|---|
| `CARRY_WIN` | 252 | 累计换月跳空回看窗口（约 1 年） |
| `CARRY_THR` | 0.004 | 展期方向阈值 ±0.4%。累计跳空 > +0.4% → 只做空；< −0.4% → 只做多；中间 → 空仓 |
| `MA_FAST` / `MA_SLOW` | 20 / 60 | 趋势确认。EMA20 与 EMA60 方向必须与 carry 一致，否则空仓 |
| `VOL_TARGET` | 0.02 | 单品种日波动率目标 2%，决定手数 |
| `EXPO_CAP` | 2.0 | 单品种敞口上限 2× 权益 |
| `MIN_FILL` | 0.50 | 目标不足 0.5 手就不开（1 手会超风险 2 倍以上） |
| `MAX_LEG_LEVERAGE` | 3.0 | 1 手名义 > 3× 权益就跳过该品种 |
| `MARGIN_BUDGET` / `MARGIN_SAFE` | 0.50 / 0.60 | 总保证金预算 50%，单腿安全线 60% |
| `GAP_THRESH` | 0.03 | 单日跳空超过 3% 视为换月，计入 carry |

**调参只会改变信号频率，不会凭空变出收益**。把 `CARRY_THR` 调小 → 更多品种
进入方向状态、邮件更频繁，但都是噪声；调大 → 邮件更少、持仓更挑剔。
建议先按默认跑 1~2 个月，看实际信号节奏再动。

**选品种偏差必须说清楚**：FG+HC 是在全样本排名里挑出来的。
同样口径下换别的品种对，大多数是负的：

| 品种对 | 年化 | 最大回撤 |
|---|---|---|
| FG+HC | +14.8% | 26.0% |
| FG+RB | +13.2% | 21.7% |
| C+CS（玉米+淀粉） | −0.5% | 40.4% |
| M+RM（豆粕+菜粕） | −1.6% | 70.6% |
| TA+MA（PTA+甲醇） | −12.3% | 99.1% |
| AU+AG（沪金+沪银） | **−100%（爆仓）** | — |

41 品种**不挑**的平均只有 +2.5%/年。所以对 FG+HC 的合理预期应落在
**2.5% 与 14.6% 之间**，而不是直接照搬 14.6%。样本外 ≈ 样本内（14.6% vs 15.0%）
是唯一的正面证据，但它不构成干净的样本外检验 —— 挑品种时用了全部数据。

### 脚本里的两个安全设计

- **杠杆护栏** `MAX_LEG_LEVERAGE = 3.0`：单腿名义超过权益 3 倍直接不做。
  1 手沪金名义 90.9 万 = 45 倍权益，2 万账户上必爆仓 —— 上表 AU+AG 的 −100%
  就是这么来的，护栏会把它拦在回测之外。
- **复权价与真实价分离**：复权序列锚定在最早一根 K 线，最新价不是真实现价。
  信号与收益用复权价，下单一律用真实价（`real_px()`）。

## 数据与局限

- **数据源**：新浪财经主力连续日线，43 个品种，最长 2009-01 至今（约 4300 根）。
- **大商所（DCE）合约级数据不可得**：交易所接口有反爬（HTTP 412），
  `akshare.get_futures_daily` 报 `JSONDecodeError`；INE 报 SSL 错误。
  故只能使用主连日线，无法做展期曲线的精确重建。
- **换月判定用阈值**：`|跳空| > 3%` 视为换月。真实的涨跌停跳空会被误判，
  引入少量噪声。更严谨的做法需要合约代码（当前数据没有）。
- **展期收益 carry 信号**：用主连的换月跳空作为 carry 代理。
  它是**唯一**不能从复权序列重算的信号，故 `load()` 在复权前把跳空留档在
  `bar["gap"]` 字段里。
- **未考虑**：保证金占用与追加保证金、涨跌停无法成交、流动性冲击、
  交割月限制。实盘需按自己的资金与合约做仓位映射。
