# 中国商品期货日线趋势策略 —— 研究工具

一个不依赖任何付费数据的商品期货策略研究框架：拉数据 → 修正数据 → 扫描信号 →
参数寻优 → 严格校验 → 生成报告。

```bash
python ft.py check        # 数据体检：换月跳空诊断
python ft.py scan         # 14 类信号族全样本扫描
python ft.py bias         # 随机信号控制实验：量化残余漂移
python ft.py explore      # 成本敏感性 / 参数寻优 / 样本内外秩相关
python ft.py bench        # 基准对照：买入持有 / 截面动量反转 / 波动率 / 止损
python ft.py surface      # (快线,慢线) × 止损 参数曲面
python ft.py validate 时序动量250   # 完整校验（可指定任意信号）
python ft.py rank         # 逐品种归因：最终策略单独跑每个品种，排出收益最高的品种
python ft.py report       # 生成单文件 HTML 报告

python strategy_top2.py            # 打印今天的信号 + 跑回测
python strategy_top2.py signal     # 只打印今天的信号（不发邮件）
python strategy_top2.py notify     # 检查信号变动，有变动就发邮件（定时任务调用）
python strategy_top2.py backtest   # 只跑回测
python strategy_top2.py refresh    # 只更新行情数据
python strategy_top2.py test-mail  # 发一封样例邮件，验证邮箱配置
```

环境变量 `FT_RAW=1` 可切回**未复权**主连序列，用于对照实验。

---

## 最重要的发现：主连不是可回测序列

新浪"主连"是主力合约的**不复权拼接**。换月当天价格直接跳到新合约价位，
产生一次跳空。**这个跳空不是交易者能拿到的盈亏。**

算例：近月 100、远月 105（contango）。

| | 原始主连 | 真实持仓 |
|---|---|---|
| 换月当天 | 100 → 105，记 +5% | 卖 100 的合约、买 105 的合约，损益 0 |
| 换月之后 | 新合约从 105 向现货收敛 | 同左，**亏 5%** |
| 一轮净结果 | **+0%**（跳空被记成盈利） | **−5%** |

原始序列把"亏损"记成了"盈利"。后果是毁灭性的：

| 信号 | 原始主连 | 复权后 |
|---|---|---|
| 截面动量 N=250 | **−22.8%** | **+12.8%** |
| 截面反转 N=250 | **+6.4%** | **−23.5%** |

**符号完全对调。** 这解释了为什么大量用主连做的回测会得出
"中国商品期货动量失效、是反转市场"的错误结论。

`ft.py` 的 `_adjust()` 做**比例复权**：把换月日整根 K 线乘以累计因子
`k *= 前收/今开`，使复权后 open 与前收严丝合缝，日内涨跌幅不变，
累计因子只依赖当日及此前的换月，**不含未来信息**。

数据体检实测：43 个品种中 **34 个**换月跳空累计为正，中位 **+48.7%**。

### 推荐配置：carry+趋势

"展期结构"与"价格趋势"同向才持仓。

| 校验项 | 结果 |
|---|---|
| 多空对称年化 | +2.5%，回撤 10.7%，Sharpe 0.59 |
| 只空侧 | **+0.4%**（不依赖市场上涨，是真 edge） |
| 样本内 2009–2018 | +2.0% |
| 样本外 2019–2026 | **+3.1%**（外样本更好） |
| 分块自助 1000 次 | 90% 区间 [0.8%, 4.2%]，**年化为负概率仅 1.0%** |
| 5× 成本压力 | **+0.1%（仍为正）** |
| 逐年 | 17 年中仅 3 年为负，且幅度小 |

参数曲面（快线 × 慢线，无止损）是一整片 **+2% ~ +3.5% 的平台**，
无孤立尖峰 —— 稳健而非过拟合。

### 两条反直觉但稳健的结论

1. **日线硬止损是负贡献。** 止损越紧、整体越差（单调）。
   日线级别止损主要在震荡里反复砍仓。真正的保护来自**仓位**，不是止损线。
2. **降低换手不解决问题。** "低换手时序动量"反而比原版差，
   说明成本不是唯一瓶颈；但低换手信号（250 日动量、carry）确实成本占比最小。

### 执行时点：「T+1 开盘」其实是当晚 21:00 夜盘

中国期货的一个**交易日** = **前一自然日 21:00 夜盘 + 当日日盘**。
所以日线 K 线的开盘价，就是前一晚夜盘的集合竞价价。

实测验证（玻璃 FG，2026-10-12）：

| 来源 | open | high | low | close |
|---|---|---|---|---|
| 10-09 夜盘 + 10-12 日盘 合并 | 870 | 875 | 860 | 863 |
| 实际日线 2026-10-12 | 869 | 875 | 860 | 863 |

完全吻合 —— 日线 10-12 那根，装的正是**周五晚 21:00 到周一 15:00**。

**这意味着两件事：**

1. **T 日收盘出的信号，最早能成交的时点是 T 日当晚 21:00**，不是第二天 9:00。
   策略回测假设的「T+1 开盘」= 当晚 21:00 夜盘。拖到第二天 9:00 下单，
   就比回测假设晚了 12 小时，成交价会系统性偏离。
2. **运行脚本的时点本身不敏感** —— 15:30（数据发布）到 20:55 之间任何时点跑，
   信号**完全一样**，因为信号只依赖已收盘的日线。跑早跑晚只影响你多早看到提醒。

**所以「开盘前 1 小时跑」是合理的 —— 而且早盘、晚盘各跑一次更好：**

| 跑的时刻 | 对应开盘 | 结论 |
|---|---|---|
| **20:00（已采用）** | 夜盘 21:00 | ✅ 最早能成交的时点，也是回测假设的 T+1 开盘 |
| **08:00（已采用）** | 日盘 09:00 | ✅ 第二道提醒，防止错过当晚夜盘时点 |
| 16:00 | — | 数据已定稿但偶有发布延迟 |

**早盘 08:00 那次有个陷阱，脚本已经处理掉了：**
一个交易日要到 **15:00 日盘收盘才算走完**。08:00 时数据源很可能已经给出
"今天"那根 K 线 —— 但它只装了前一晚的夜盘，**没走完**。拿它算信号，
基准日会从上一交易日错到今天，信号可能是错的。
所以 `load()` 里加了护栏：**当天 15:00 之前出现的"今天"这根 K 线一律剔除，
只当"最新价"用**。这样早盘那封的信号基准仍是上一交易日收盘（正确），
而浮盈用的是夜盘收盘的最新价（更有参考价值）。
实测：喂一根假的"次日残 K"，信号基准日正确回退到上一交易日，最新价取到残 K 的收盘价。

**例外与提醒：**
- **长假前最后一个交易日没有夜盘**，那天要等下一个交易日 9:00 才能执行。
- **夜盘流动性比日盘差**，22:30 之后尤其明显；1~2 手的小单问题不大，仓位大了要留意滑点。
- 你池子里的 10 个品种夜盘收盘时间：多数到 **23:00**，沪镍 NI 到 **01:00**。

### 邮件通知（每个交易日两封：早盘前 + 晚盘前）

`python strategy_top2.py notify [am|pm]` 会：
1. 先用 akshare 更新行情数据（`refresh`）
2. 剔除当天还没走完的 K 线，比对 `signal_state.json` 里上次记录的仓位，
   算出**开仓/加仓/减仓/平仓/反手**
3. 按变动与否决定邮件形态，然后发送

**两场用不同的去重键**（`notified.am` / `notified.pm`），所以同一天两封都会发；
但同一场重复运行不会重复发。不写 `am`/`pm` 时按当前小时自动判断。

| 情形 | 标题 | 正文 |
|---|---|---|
| **有仓位变动** | `【⚠ 期货信号·有变更】10-12  玻璃 空→平仓` | 红色标题条 + 操作清单表 + 持仓盈亏表 |
| **无仓位变动** | `【期货信号·持仓】10-12  浮盈 6,960 元` | 深色标题条 + 持仓盈亏表 + 跟踪权益 |

两封的差别：早盘那封会用**夜盘最新价**算浮盈，晚盘那封用**当日收盘价**。

正文表格：`table-layout:fixed` + `<colgroup>` 固定列宽 + 数值列右对齐，
390px 窄屏实测不折行、不截断；另有纯文本兜底。**红盈绿亏**（中国市场习惯）。

**盈亏怎么算的**：`signal_state.json` 记录每腿的开仓价与开仓日期。
- 开仓 → 记当日收盘价；加仓 → 加权平均成本；减仓 → 成本不变、兑现部分盈亏；
  反手 → 先平旧仓再按新价记；平仓 → 结算进 `realized`。
- 浮动盈亏 =（现价 − 开仓价）× 方向 × 手数 × 合约乘数。
- 跟踪权益 = 起始权益 + 已实现 + 浮动；改 `EQUITY` 会自动重置跟踪基线。

| 命令 | 作用 |
|---|---|
| `notify` | 正常推送（数据没更新就跳过，避免同一天重复发） |
| `notify daily` | 强制发送，手动随时想看就用这个 |
| `notify test` | 只把邮件内容打印到屏幕，不真发 |
| `notify nofetch` | 跳过联网更新，直接用本地 CSV |
| `test-mail` | 发两封样例（有变更 / 无变更），验证格式与邮箱配置 |

由 `安装定时任务.bat` 注册的两个 Windows 计划任务在工作日 **08:00** 和 **20:00**
自动调用（另有 WorkBuddy 定时任务 08:20 / 20:20 兜底，同一场次不会重复发）。
这两个时点都是按「开盘前 1 小时」定的，理由见上一节。

### 什么参数会触发推送

**每个交易日都会推一封**，推送本身由数据更新触发；「有没有仓位变动」只决定标题形态
（有变动 → 高亮提醒；无变动 → 报持仓与盈亏）。一次 `notify` 的判定链：

1. 用 akshare 刷新行情。若 `data_date` 与 `signal_state.json` 里记录的相同
   （当天已经推过了）→ 跳过，**同一天不重复发**。
2. 否则用当日收盘数据重算每个品种的三条腿信号，与上次记录的仓位比对。
3. 有变动 → 标题带 `⚠ 有变更` 并列出操作清单；无变动 → 标题直接报浮盈/浮亏。

真正决定「有没有信号、什么时候开平仓」的是这几个参数：

| 参数 | 默认 | 作用 |
|---|---|---|
| `CARRY_WIN` | 252 | 累计换月跳空回看窗口（约 1 年） |
| `CARRY_THR` | 0.004 | 展期方向阈值 ±0.4%。累计跳空 > +0.4% → 只做空；< −0.4% → 只做多；中间 → 空仓 |
| `MA_FAST` / `MA_SLOW` | 20 / 60 | 趋势确认。EMA20 与 EMA60 方向必须与 carry 一致，否则空仓 |
| `VOL_TARGET` | 0.025 | 单品种日波动率目标 2.5%，决定手数 |
| `EXPO_CAP` | 2.0 | 单品种敞口上限 2× 权益 |
| `MIN_FILL` | 0.50 | 目标不足 0.5 手就不开（1 手会超风险 2 倍以上） |
| `MAX_LEG_LEVERAGE` | 3.0 | 1 手名义 > 3× 权益就跳过该品种 |
| `MARGIN_BUDGET` / `MARGIN_SAFE` | 0.50 / 0.60 | 总保证金预算 50%，单腿安全线 60% |
| `GAP_THRESH` | 0.03 | 单日跳空超过 3% 视为换月，计入 carry |

**调参只会改变信号频率，不会凭空变出收益**。把 `CARRY_THR` 调小 → 更多品种
进入方向状态、邮件更频繁，但都是噪声；调大 → 邮件更少、持仓更挑剔。
建议先按默认跑 1~2 个月，看实际信号节奏再动。

**选品种偏差必须说清楚**：FG+HC 是在全样本排名里挑出来的，41 品种**不挑**的
平均只有 +2.5%/年。所以对 FG+HC 的合理预期应落在 **2.5% 与 19.0% 之间**，
而不是直接照搬 19.0%。样本外 ≈ 样本内（18.4% vs 19.3%）是唯一的正面证据。

## 第三轮复验：想超过 FG+HC，试过哪些路、结果如何

先交代一件事：第二轮报告里 FG+HC 写的是 **10.8%**，而你实际在跑的
`strategy_top2.py` 是 **15.4%**。差在口径 —— 前者是 `ft.py` 的无杠杆等权口径，
后者带 `VOL_TARGET` 波动率目标与 1 手最小单位。**拿 6.6% 的横截面去比 15.4%
本身就是不公平的**，同口径下 FG+HC 是 10.8% vs 6.6%。

把口径拉平后，2026-10-20 逐条试了所有"能提收益"的路：

| 尝试 | 结果（同口径） | 判定 |
|---|---|---|
| 横截面 carry 全池 K=5 | 6.55% / 11.6% | 收益更低，回撤小一半 |
| 横截面 carry K=2 | 7.99% / 22.9% | 仍需 11 万资金 |
| 小额横截面（保证金<5000 池） | 最好 6.23% | 池子砍掉 CU/NI 后 alpha 塌了 |
| FG+HC 加 RB | 11.10% / **38.7%** | 年化几乎不变，回撤翻倍 |
| FG+HC 加 RB+SA | 10.78% / 38.7% | 无效 |
| FG+HC 混 20% 横截面 | Calmar 0.69→0.88，年化降 | 只降波动，不提收益 |
| FG+HC + ATR 止损 | 10.82%→10.14% | 止损打断慢变量，反亏 |
| **FG+HC 提高目标日波动** | **10.82%→16.52%** | **唯一有效** |

**加品种为什么失败**：RB 螺纹与 FG/HC 同属地产链，三者回撤同步发生，
等权分散直接失效，组合回撤被拉到最差单品种水平（38.7%）。

**重新做了一遍品种全组合搜索**（2 万开得起 + 多空两侧都为正 + 样本内外都为正，
27 个可行组合）：

| 品种组合 | 年化 | 回撤 | Calmar | 样本内 | 样本外 |
|---|---|---|---|---|---|
| **FG+HC** | **10.82%** | **15.7%** | **0.69** | 8.92% | 12.33% |
| FG+HC+SA | 9.88% | 14.8% | 0.67 | 8.92% | 10.64% |
| FG+RB | 11.45% | 38.7% | 0.30 | 13.37% | 9.07% |
| FG+PF | 10.67% | 29.2% | 0.37 | 10.27% | 10.98% |

年化最高的 FG+RB 只比 FG+HC 高 0.6pct，代价是回撤多 23pct、Calmar 腰斩，
且样本外衰减 32%（过拟合）。**FG+HC 经得起复验，仍是 2 万元下的最优品种对。**

### 唯一有效的提收益手段：加杠杆

`strategy_top2.py` 实盘口径（含 1 手最小单位与保证金约束）扫 `VOL_TARGET`：

| 目标日波动 | 年化 | 最大回撤 | Calmar | Sharpe | 样本内 | 样本外 |
|---|---|---|---|---|---|---|
| 2.0%（旧） | 15.41% | 23.4% | 0.66 | 0.97 | 11.33% | 18.03% |
| **2.5%（现在）** | **18.96%** | **25.1%** | **0.76** | **1.05** | **18.39%** | **19.31%** |
| 3.0% | 19.69% | 27.6% | 0.71 | 0.93 | — | — |
| 3.5% | 20.65% | 31.9% | 0.65 | 0.86 | — | — |
| 4.0% | 25.00% | 37.5% | 0.67 | 0.93 | — | — |

**2.5% 是 Calmar 与 Sharpe 的双重点**，比旧 2.0% 一年多赚 3.5pct，样本内外
还一致（18.4% vs 19.3%）。代价是最差年份从 **2017 的 −7.0%** 变成 **2023 的 −11.7%**
（亏损年份反而从 5 个减到 4 个）。想把 `VOL_TARGET` 改回 0.02 即回到旧档，
一个参数的事。

### 脚本里的两个安全设计

- **杠杆护栏** `MAX_LEG_LEVERAGE = 3.0`：单腿名义超过权益 3 倍直接不做。
  1 手沪金名义 90.9 万 = 45 倍权益，2 万账户上必爆仓 —— 上表 AU+AG 的 −100%
  就是这么来的，护栏会把它拦在回测之外。
- **复权价与真实价分离**：复权序列锚定在最早一根 K 线，最新价不是真实现价。
  信号与收益用复权价，下单一律用真实价（`real_px()`）。

## 为什么不是黄金（附实测）

「黄金策略收益高」这句话需要拆开看。同一套 `carry+趋势` 搬去沪金沪银，结果：

| 品种 | 全样年化 | 回撤 | Calmar | 只多 | 只空 | 1手保证金 | 可行 |
|---|---|---|---|---|---|---|---|
| AU 沪金 | **+0.4%** | 45.9% | 0.01 | +1.1% | −0.7% | 127,210 | × |
| AG 沪银 | **+0.6%** | 56.8% | 0.01 | +3.2% | −2.5% | 30,906 | × |
| AU+AG 组合 | +0.8% | 50.8% | 0.02 | — | — | — | 年化为负概率 42.2% |

对照 FG+HC 的 +18.96% / 25.1% / Calmar 0.76：**策略在贵金属上是净亏手续费**。

### 「黄金收益高」高在哪里

| 口径（AU，2009-01 ~ 2026-10） | 年化 | 回撤 |
|---|---|---|
| 买入持有（永远满多） | +11.1% | 51.1% |
| 纯 MA 趋势、只做多 | +10.4% | 57.2% |
| **carry+趋势（本策略）** | **+0.4%** | 45.9% |

趋势只多比买入持有**还差 0.7 个点**——说明黄金上「策略」做的唯一事情就是
把自己暴露在市场涨跌里，**没有任何 alpha**。黄金从 2009-01 的 190 元/克涨到
现在的 909 元/克（4.8 倍），那 11% 是金价本身的 beta，换个交易方式不会变多。

同一张表看玻璃，结论反过来：买入持有 **−10.7%**（MDD 98%），
纯趋势只多 +5.6%，**carry+趋势 +11.9%** —— 超出的部分才是策略真赚的。

### 技术原因：carry 腿在黄金上失效

这条策略的一半收益来自展期结构（contango 做空、backwardation 做多），
而**黄金没有展期结构**：它没有工业消费、没有季节性库存周期，
近月远月价差极薄且方向不稳定。实测 AU 上有 **46% 的交易日处于空仓**
（1987/4320 天），信号不是在多空之间切换，而是根本不出信号。

按本策略的入池标准（**只多、只空都必须为正**）——AU 只空 −0.7%、
AG 只空 −2.5%，两个都**不合格**，收益全来自市场上涨。

### 资金原因

AU 乘数 1000 克/手，按现价 908.6 元/克算：

- 1 手名义 **908,640 元**，保证金约 **127,210 元**（含期货公司加收）
- 2 万本金连 1 手都开不了；`MAX_LEG_LEVERAGE = 3.0` 会直接跳过该品种
- 30 万本金开 1 手，单腿**名义敞口 3 倍、保证金占用 42%**，等于满仓赌方向

复现命令：`python ft.py rank AU AG`

> 这条命令会把 `rank.json` 覆写成只有 AU/AG 的版本。
> 报告 `ft.py report` 需要全池归因，重跑一次 `python ft.py rank` 即可恢复。

### 结论

**黄金是「配置」不是「策略」。** 如果你长期看好金价，正确的做法是买
黄金 ETF 或实物长期持有（无展期成本、无杠杆、可隔夜睡觉），
而不是把费率和杠杆放大 10 倍的期货搬进来。想用期货做多黄金，
本质上是在用 12.7 万保证金赌 90 万的方向——那个「高收益」是金价给的，
风险却是杠杆给的。

## 第二轮探索：有没有更好的策略

有。完整报告见 **`期货策略第二轮研究报告.html`**（单文件，离线可看）。这里只放结论。

### 换维度的那个发现：横截面展期因子

第一轮已经证明：41 个品种不挑不选地等权跑任何**时序**策略，
年化都在 −10% ~ +3.7% 之间——「每个品种独立判断方向」这条路几乎没有 alpha。

于是换成**横截面**：不问「这个品种该做多还是做空」，而问「今天 41 个品种里谁最贵、谁最便宜」。
每天按过去 252 日累计换月跳空排序，**做多最负的 5 个（backwardation 最强）、
做空最正的 5 个（contango 最强）**，多空金额对冲。

| 指标 | 数值 |
|---|---|
| 全样本年化 | **6.55%** |
| 最大回撤 | **11.6%** |
| Calmar | **0.56** |
| Sharpe | **0.84** |
| 样本内 2009-2018 | 3.68% |
| 样本外 2019-2026 | **10.39%**（外优于内） |
| 自助「年化为负」概率 | **0.7%** |
| 18 个年度中亏损年数 | **2 年**（2011、2024） |

**最值钱的是相关性**：它与现有 FG+HC 策略的日收益相关系数只有 **0.19**。
各出一半，组合后年化 9.70%、回撤 **9.7%**、Calmar **1.00**、Sharpe **1.15**——
比任何一个单独跑都强，因为两者的回撤不在同一天发生。

### 但它需要 29 万本金

这个因子必须同时持有 **10 个品种**（5 多 5 空），1 手保证金中位数 **14.5 万**，
按保证金占权益 50% 反推需要 **29 万**。而且**缩不了水**：

| K | 同时持仓 | 年化 | 回撤 | Calmar | 1手保证金中位 | 建议本金 |
|---|---|---|---|---|---|---|
| 1 | 2 腿 | 5.07% | 35.8% | 0.14 | 20,848 | 41,696 |
| 2 | 4 腿 | 7.99% | 22.9% | 0.35 | 55,060 | 110,119 |
| 3 | 6 腿 | 7.33% | 19.9% | 0.37 | 87,597 | 175,193 |
| 4 | 8 腿 | 6.45% | 17.2% | 0.38 | 113,635 | 227,269 |
| **5** | **10 腿** | **6.55%** | **11.6%** | **0.56** | **145,190** | **290,381** |

我试过把池子缩到 8 个精选品种做 K=2，年化直接掉到 **0.03%**——
alpha 来自 41 个品种的广度，腿少了排序就没有区分度。**这条路没有便宜的替代方案。**

### 三条死路（别再试）

- **产业链配对价差**：10 对（豆粕/菜粕、螺纹/热卷、焦炭/焦煤……）**9 对亏钱**，
  持仓胜率只有 44~49%。商品价差由产能周期、库存、政策驱动，有强趋势性，均值回归假设不成立。
- **横截面动量**：短周期（20/60 日）全负，250 日才勉强转正，Calmar 0.21，明显弱于 carry。
- **短周期反转**：RSI 回归 −4.0%、布林回归 −5.7%，全负。

### 品种池的调整

按「样本内、样本外都为正」重筛 41 个品种后，**焦炭 J 已从池子里剔除**：
全样本 +14.7% 看着漂亮，但样本内 +34.5%、**样本外 −2.0%**，典型的过拟合。
池子现在到 20 万（橡胶 RU）为止，共 9 个品种。

最稳的三个：**玻璃 FG**（内 10.3% / 外 12.4%）、**沪镍 NI**（Calmar 0.55 最高）、
**热卷 HC**（内 5.9% / 外 11.0%）。

## 数据与局限

- **数据源**：新浪财经主力连续日线，43 个品种，最长 2009-01 至今（约 4300 根）。
- **大商所（DCE）合约级数据不可得**：交易所接口有反爬（HTTP 412），
  `akshare.get_futures_daily` 报 `JSONDecodeError`；INE 报 SSL 错误。
  故只能使用主连日线，无法做展期曲线的精确重建。
- **换月判定用阈值**：`|跳空| > 3%` 视为换月。真实的涨跌停跳空会被误判，
  引入少量噪声。更严谨的做法需要合约代码（当前数据没有）。
- **展期收益 carry 信号**：用主连的换月跳空作为 carry 代理。
  它是**唯一**不能从复权序列重算的信号，故 `load()` 在复权前把跳空留档在
  `bar["gap"]` 字段里。
- **未考虑**：保证金占用与追加保证金、涨跌停无法成交、流动性冲击、
  交割月限制。实盘需按自己的资金与合约做仓位映射。
